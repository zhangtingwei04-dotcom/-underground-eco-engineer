訪客存檔跨網站轉移 · V0.1

這個工具只在你目前的瀏覽器運作。 不會把存檔上傳到伺服器，也不會輸出登入權杖、帳號資料或 Supabase 金鑰。

請先把 JSON 備份存到 iPhone「檔案」App 或其他安全位置，再到新網址匯入。不要公開分享備份檔。

① 舊網站：下載訪客備份

只讀取目前舊網址的訪客存檔與舊生態箱資料。若原本沒有訪客存檔，會明確提示，不會憑空建立。

② 已儲存檔案 → 前往新網站匯入

② 新網站：檢查並匯入備份

選擇先前從舊網址下載的 JSON。匯入會先放入隔離暫存區，不會立即覆蓋遊戲進度。

無法在此網址操作

為避免備份誤匯入陌生網站，本工具只允許原本 GitHub Pages 舊網址匯出，以及正式 Cloudflare Pages 新網址匯入。

正在確認網站…

本工具不處理已登入帳號的雲端存檔。帳號雲端同步必須在登入系統另外驗收，不能只靠轉移檔案。
