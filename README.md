# 地下生態工程師 (Underground Eco-Engineer)

一款結合地下探索、生物管理與棲息地建設的雙語生態模擬遊戲。

- [x] 建立 GitHub 雲端開發儲存庫

- [x] 定義核心生物：豬鼻蛇屬性數據 (`src/entities/hognose.json`)
- [x] 設計核心機制：挖掘與能量消耗系統 (`src/systems/digging-system.js`)

## 🐍 核心生物設定
* **豬鼻蛇 (Hognose Snake)**：基礎挖掘力 15。生性膽小但擅長在沙土中挖掘，遇到威脅時是個演技派的裝死高手。
