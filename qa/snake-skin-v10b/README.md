# 公開暖脈枝蛇蛇皮試驗室｜V1.0Q / V1.0T / V1.0V

經開發者同意，公開本套**早期測試蛇皮**、獨立的 WebGL2 預覽和必要的畫面檢查程式。這不是最終遊戲畫面、美術定稿或實體蛇生理模擬。

[開啟公開 Q/T WebGL2 測試頁](visual/warmvein-v10b-test.html)：預設新版 V1.0T，另可選 V1.0Q、V1.0U 同一來源影格 Q/T 左右比較；可切換不同成長階段、頭部特寫與嘗試擷取 V1.0V 真 GPU 本機 PNG。

來源骨架使用本公開儲存庫 qa/snake-motion/src/ohm-core 的 V0.9T/U 模組。私人遊戲、NPC、玩家帳號與雲端存檔**不在本次公開範圍**，公開 QA 不應連向私人儲存庫。

通過程式測試不等於美術已通過，更不代表 iPhone Safari 實機測試完成。未來可以持續新增和改善不同款式的皮膚。已進入 Git 歷史的公開資料，無法保證日後刪除即可撤回。

## V1.0Y 頭部重塑及攝影機驗收（工程候選）

已依玩家提供的側面、正面及斜側面參考照片，加入獨立原創 **V1.0Y 顯示層**：利用現有 V0.9R/U 八組真頭環的局部正交軸收窄吻部、頭頂與頰部，縮小獨立眼睛，依攝影機選擇各側較靠上方的真頭表面頂點；V1.0X 遠側眼遮擋繼續保留。**不曾取得、匯入、複製或購買 Meshy 3D 模型。**

新增「V1.0Y：舊 R／新 Y 同幀頭型比較」與頭部近景 PNG。修正左右分割畫面的世界單位／像素比例，避免舊版垂直方向遭過度放大，讓後續外形調整有可信的畫面基準。保留 24 節原骨架、共用第 8 頸環、全部身體環、原 UV、三角面、碰撞、成長階段與玩家存檔。

[公開 V1.0Y 真 Chrome QA（雙橫式、8 張圖）](https://github.com/zhangtingwei04-dotcom/-underground-eco-engineer/actions/runs/43461147526)；單元、WebGL2、兩視窗一眼遮擋、Q/T 顏色差異和 R/Y 真 GPU 像素差異已通過。**美術尚未通過最終驗收**：鼻孔、上下顎、立體轉向、頭與頸的精緻比例、正面／斜面多角度，仍須建模及動態測試；目前 Chrome 只驗收固定攝影機的側面，不應宣稱完成三角度。Q/T 為公開實驗皮膚；私人正式遊戲仍未接受此顯示層。
