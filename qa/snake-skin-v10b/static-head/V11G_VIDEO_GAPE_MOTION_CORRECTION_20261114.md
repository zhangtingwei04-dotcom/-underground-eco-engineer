# 暖脈枝蛇 V1.1G｜不再固定頭部：真蛇影片與開嘴動作的差異

日期：2026-11-14（台灣）。狀態：**獨立 WebGL2 動作研究候選；未經最終美術／生物力學驗收。**

## 真正重新核對的來源

使用者先前上傳 `ScreenRecording_11-08-2026 21-16-20_1.mp4`。本輪重新抽取**約 22.3 秒（閉嘴）與 25.1 秒（張至很大）**的原始影片影格。它呈現：

- 張嘴時**上方吻端在畫面中往上抬，嘴巴下緣往下延展**；鼻端及眼睛與頭的主輪廓一起改變方向。
- 頭後方仍有頸部支撐，不是整顆上顎像機械蓋子單獨掀開。
- 嘴巴打開後有明顯維持，再緩慢閉回原本的頭型；不是單純一張 46° 的固定照片。
- 影像中只有部分可見的輪廓。**單機位影片無法區分頭部俯仰與顎骨的完整 3D 關節角度**。以下角度與時間線都是測試起點，並非從影片精密量測所得。

## V1.1F 過去錯在哪裡？

之前只有 `rotateLower()` 讓下顎下降。上方頭骨、眼睛、鼻端全部保持原座標，不會隨張嘴抬頭。雖然四張固定開口圖可以通過 Chrome 截圖測試，但這種**只改下顎、整顆上方頭固定**的動作，不符合來源影片看到的姿態變化。

過去若直接說「下顎是主要動作，所以不應動上顎」，容易忽略參考影片拍到的**整顆頭抬起**。正確的試驗方式：保留顎部相對運動，同時讓頭頸一起轉動，而非讓上顎像盒蓋翻開。

## V1.1G 真正新增的程序控制

- `warmvein-gape-motion-v11g.mjs`：建立兩個**相互獨立的顯示自由度**：
  1. `lowerJawRelativeGapeDegrees`：下顎相對頭骨的張口程度，0–46°；原始 V1.1F 顎部結構與皮膜仍由同一組曲面生成。
  2. `headPitchDegrees`：整顆頭與嘴巴的共同向上俯仰；後段頸部從固定根環逐漸過渡，不讓整顆頭浮離身體。
- 提供三個可比較方案，而不是預設一個比例一定正確：
  - `lower-only`：舊模型，頭不仰（0°）。
  - `video-head-lift`：新候選，最大頭部仰角 14°。
  - `upper-dominant`：另一個較明顯的仰頭候選，最大 23°。
- 新增 0–100% 時間軸，以閉嘴→張開→維持→收嘴→閉嘴的過程進行真正 WebGL2 更新。這只是**初步定性時間曲線**，不是逐幀動作追蹤。
- `v11g.html`／`v11g-viewer.mjs`：可在手機橫式檢視中切換顎部方案、四個角度、頭部近景與休息盤繞，使用「播放／暫停／時間軸」比較。
- 新版只在公開靜態實驗室動作模型改動，保留 V1.1F 原始程式、24 節正式骨架、原 UV、碰撞與存檔不變。

## 品質驗收不可混為一談

1. **單元測試**：舊方案頭頂不能上移；新方案相同上顎幾何的前段頂點必須上移；頸根仍不動；張嘴與收嘴連續且可以回到原位；同幀眼睛、嘴巴和頭部整體一致。
2. **真正 GPU 截圖**：同側／同斜側／同正面、相同口型下分別渲染三種方案；測試不同方案真像素不同，不得只改文字；另外至少三個時間軸位置有畫面差異。
3. **人眼藝術對照**：以前述 22.3、23.1、23.6、24.4、25.1、25.8、26.6 秒逐格觀察。應評估頭部抬升、下顎長度與弧度、口角位置、閉嘴復原，而不是只問張口最大角度。
4. **限制**：即使數值和 Chrome 測試通過，仍不能稱為已符合影片或真實蛇的咽喉、上顎、顱骨生物力學。若鼻端往上翹得過大、頸部出現折線、下巴反向穿模，必須繼續修。
