# 暖脈枝蛇 V1.1D｜過長吻部的定向修正與真 3D 驗收

日期：2026-11-14（台灣）｜公開靜態模型實驗。**吻部比例修正已實作並通過工程驗收；整體美術尚未通過。**

## 使用者指出的問題
V1.1C 眼睛至鼻端過長，前半頭像扁長楔形。不能只把頭尖切掉，否則會變成平鼻或分離的上下顎。本版根據先前使用者提供的真蛇影片，以及側面／正面／斜側的 Meshy 參考截圖，僅自行重建幾何；不取得或複製付費 3D 模型。

## 真正修改與量測的項目
- 新版獨立頭部網格 `warmvein-static-anatomy-v11d.mjs`：以原 V1.1C 眼睛中心的 `x=-0.12904` 為不動定位點，將眼前方位置沿前向軸以 `0.68` 比例重新映射；原眼到鼻端 `0.29952` 世界單位，V1.1D 鼻端額外加 `0.015` 世界單位的立體圓弧封口後，總長約 `0.2187`，縮短約 **26.98%**。
- 鼻孔同樣依眼前位置比例映射；上下顎前端用新相同前向座標系計算，不會只縮短顱骨而留下突出下顎。
- 鼻端新增真正由三角面形成的弧形 3D 封口，不是 UV 畫出來的圓鼻子。
- **固定**原眼睛中心、後方顎部支點、頸部定位、原有四種張嘴角度與身體盤繞曲線；測試版仍未接入正式 24 節骨架。
- V1.1C 原版完整保留，方便直接做同角度對照。

## 已執行的檢查
- `warmvein-static-coil-v11d.test.mjs`：四口型、左右下顎、圓鼻端面片、眼前與頭寬比例、鼻孔落在鼻端後方、頭部原始定位、口型遞增、身體不重疊靜態檢查。
- `warmvein-static-coil-v11d-chrome.mjs`：2 組顯示模式（全身盤繞／頭部近景）× 4 種靜態口型 × 4 個攝影機角度，共 **32 張實際 WebGL2 PNG**，且檢查 V1.1D 頭型縮短幅度與圓鼻端標記。
- GitHub Actions：<https://github.com/zhangtingwei04-dotcom/-underground-eco-engineer/actions/runs/43513363872>。程式與真 GPU 兩個工作均成功；32 張圖的 artifact 名為 `public-warmvein-v11d-short-snout-32-views`。
- 自行目視 C／D 相同角度的閉嘴比較：新的鼻端較短、較圓，原本尖長楔形有所減輕。

## 仍未通過的美術項目
1. 整個上顎／頭頂外觀仍偏扁，近視角的骨量與顎部立體感不足。
2. 頭頸銜接的幾何還偏直，不能只靠顏色接縫掩飾。
3. 張大嘴時下顎仍顯細長板狀，口腔內壁／軟組織尚缺少層次。
4. 全身靜態盤繞仍偏規則的管形，未達到「第一眼就是自然的蛇」的最終驗收門檻。
5. Chrome 工程成功不等同 iPhone Safari 實機驗收、真蛇生理解剖認證或正式遊戲整合。

**結果**：使用者指名的「吻部過長」已完成具體幾何比例修正；保留為 V1.1D 靜態模型候選。下一輪仍以閉嘴多角度形體、頭頸和顎部層次為主，先過靜態美術再考慮動作。
