# V0.9G 公開中立透明蛇｜折返全身轉彎半徑預警

日期：2026-11-13（台灣時間）

## 目的

V0.9F 透明頭頸／軀幹／尾部在 24-joint 真來源上逐幀一致，但回程 V0.9C 第 530 幀形成過緊的局部線圈；原 V0.9D 僅於第 531 幀拒絕後續候選。這次不以縮細蛇身、畫上皮膚、假裝蛇疊身、放行 3D 穿透來解決。

## 已實作

- 新增 `src/ohm-core/snake-turn-space-v09g.mjs`，原始 24-joint／2.28 length pose 不更動，計算相鄰 **8 條來源骨節**的多節總轉角和局部等效圓弧半徑，區分同方向縮成 U 的急彎與正反抵銷的 S 彎；預設「同方向轉角 >= 1.3rad 且等效半徑 < 0.42 source units」作為**藝術與動態安全預警閾值**，不是任何現實蛇的生物學轉彎限制。
- 直接調用 V0.9D 來源骨長、三維非相鄰膠囊距離驗證；新的 V0.9G 並**沒有覆寫**原 V0.9D 身體自交／撞擊安全閘門。2D 曲率只是警報，不代表真正 3D 碰撞和支撐力已驗證。
- `advanceSnakeRouteWithTurnSpaceGuardV09g` 是 opt-in 包裝器；原 V0.9C/V0.9D 與對應測試保持不變。只在 `moving_return` 且**頭端附近的轉彎窗口**（窗口 startLink <= 2）過緊時，以 `turn_space_hold`、`renderablePose:null` 暫停；尾端承襲的舊彎曲仍列為診斷，不會獨立阻斷返程。
- 安全停止不瞬移、不縮骨節、不宣稱抵達、也不更動正式玩家存檔／正式遊戲／生態箱真值／物種美術。
- 新增 `tests/snake-turn-space-v09g.test.mjs`：24節伸直、交替 S、受控緊 U、來源不可改、非法輸入，以及原 V0.7P→V0.9C+V0.9D 的真連續 24 節折返動態測試。

## 來源動態觀察

於公開 Node QA 跑通真來源連續 trace：起始第 60 幀現有尾端縮圈警報在 links 14–15；在已進入返程後，下一個頭端 link 0 的急彎候選觸發 V0.9G，**停止於最後已接受的第 284 幀**。原 V0.9D 動態若不使用新 V0.9G，仍按原測試通過到 530、在 531 前停止。這次的成果是提前揭露「頭部回轉空間不足」，**不是證明蛇已學會自然 U-turn，更不是完成往返**。

Node 單元／整套蛇與生態回歸：GitHub Actions [#43263283236](https://github.com/zhangtingwei04-dotcom/-underground-eco-engineer/actions/runs/43263283236) 的 snake-motion-unit 工作通過。此紀錄不等於新增 V0.9G 的實拍 Chrome 對比圖；既有 V0.9F Chrome 驗證與 V0.9G 警報功能是兩件事。
