# Project OHM V0.9X｜拒食安靜期、個體食物偏好、透明蛇嗅聞與轉身的工程 QA

日期：2026-11-13（Asia/Taipei）｜**公開中立合成蛇行為工程測試**。沒有使用或公開正式原創物種設定、NPC、玩家資料；不等於真實蛇類飼養計畫、動物診斷、遊戲正式行為或完整 3D 生物力學。

## 目的與承接的真來源

- **V0.9W** 已將餵食「提出」與真正接受／拒食拆分；接受後胃內食物仍須經過模擬消化、能量維持和吸收，剩餘成長量只排入 **V0.9V 安全休息期成長佇列**，移動中不改 24 節骨長、24 個體徑或透明網格。
- 但如果玩家可以在同一個模擬時間點連續改用不同餵食事件 ID，可能反覆重抽直到接受；而舊 V0.9W 沒有個體食物偏好與可見拒食動作。
- **V0.9X** 以新的純 JS 包裝層處理真正提出食物的安全間隔、個體偏好和拒食反應；中立動作由真正已驗證的 **V0.9T 四體型 24 節動態**、**V0.9U 真體型透明網格**以及 **V0.9S 全身 3,216 三角面有限時間碰撞檢查**預演。舊 V0.9W／V0.9T／V0.9U／V0.9V 既有動態、成長與存檔不會被強制改寫。

[**GitHub Actions #43344585489**](https://github.com/zhangtingwei04-dotcom/-underground-eco-engineer/actions/runs/43344585489)：**8/8 工作成功**（包含新 V0.9X 來源 Node test）。其它 Chrome 工作為 V0.9D/F 及早期中立透明蛇畫面的歷史回歸，**不是 V0.9X 專屬拒食演出影片或 iPhone Safari 真機驗收**。

這個表格只證明此中立程式設定能隨個體偏好改變食慾；**不可拿來預測任何真實蛇種／原創虛構生物的拒食率**。

**動態驗收**：四種 V0.9T 合成體型，每種在 9 個中立個體／事件種子下測試，合計 **36 次完整拒食動作預演**：每次 3 個原地頭部／嗅聞停頓網格檢查加 4 個真正 V0.9T 尺寸化轉向影格，共 **144 幀真尺寸來源轉向**、**252 組（36×7）完整頭身網格時間切片檢查**。三種行為標籤皆有涵蓋；所有動態均保持 23 段原體型骨長及局部體徑不變、頭頸接縫與安全閘門一致。**不把 3 幀頭部微幅偏轉冒充完整嗅覺物理或舌頭動畫**。

其他通過：
- 拒食後同一時間連續換事件 ID 不會重抽，沒有食物被扣或成長量被創造；模擬時間到期才可真正再次提出食物。
- 即使已接受食物，接下來安靜期不能重新餵；其後胃中仍未消化完也會拒食。接受事件仍**只要求未來正式宿主驗證扣除物品**，本模組沒有權限寫入正式玩家庫存。
- 接受食物後**立即營養吸收 0、立即幾何成長 0**；真正營養/成長仍依 V0.9W 消化和 V0.9V 休息期檢查。
- 來源下一幀固定角度、場景與 head-body mesh 有問題則 fail-closed，沒有偷越 V0.9T/U/S 驗證，也沒有改正式遊戲或玩家雲端存檔。

## 下一階段必要條件

1. **真正可玩的拒食畫面與動作差異**：現在是動態來源預演及中立狀態標籤，不是已完成真實舌頭、鼻尖、吞嚥、退縮、躲藏的美術演出。將來應在獨立橫式瀏覽器場景與 iPhone Safari 檢查長時變形和自然度。
2. **實際退後與躲藏**：目前僅做站定後輕微轉身／離開傾向。沒有完成向後退行、真正洞穴尋路、藏身內部的物理碰撞或尾巴完整入洞判定；`seekCoverIntentOnly` 明確為 true。
3. **真世界權威交易**：當前 V0.9X 是遊戲外中立實驗，前端可以捏造輸入、設定個體偏好或修改本地時鐘；**不具身分、物品、時鐘和事件真正持久權限**。接入正式遊戲前，必須把 ID、真食物與來源、時間和取消／確認交付、權威庫存扣減做成原子交易，還要測重複登入／多端離線補算。
4. **生物研究**：食物類別分類和偏好、合適時段、物種本來的拒食習慣、蛻皮影響、環境／健康線索、營養與生長模型，需要逐物種研究；此版數值全部為中立工程，不可當實際飼育間隔或診斷。
5. **使用者決定的優先序不變**：先提升蛇的動態、真體型透明頭身和生態行為；保留已完成 V0.9W/V 的消化與休息期成長，NPC 記憶系統仍停在已保存的 V0.1 研究原型，不額外增訂付費資源。

**結論：V0.9X 已使拒食不再可用同一時間的多次點擊「刷到接受」，並在四種真尺寸骨架上完成碰撞守衛的有限嗅聞／轉向行為預演。仍不宣稱已具真正退後、尋找躲藏洞的動態能力或真實蛇食慾數據。**
