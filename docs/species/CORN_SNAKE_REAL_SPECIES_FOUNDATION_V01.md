# 玉米蛇（Pantherophis guttatus）｜首個真實爬蟲動態與個體花紋研究原型 v0.1

- 日期：2026-11-08
- 狀態：**確定首個真實爬蟲開發樣本；資料模型與科學來源建檔，不代表動畫／遺傳／飼養系統已實裝**
- 物種 ID：`pantherophis-guttatus`
- 物種類型：現實生物；與未來傳說級晶脈夜蜥的虛構資料分開。
- 優先理由：蛇身連續曲線運動、觀察／攀爬／藏匿等真實行為，以及豐富但需要科學約束的色素與花紋變異。

## 1. 動態系統先做什麼

**第一階段：運動**
- 蛇體中心線及分段姿態資料結構。
- 停止／靜止、側向波動前進、轉向、進入躲避處、環境碰撞。
- 攀爬或狹窄空間運動作為後續研究項目，不能未經驗證就把所有蛇類運動模式放入同一物種配置。
- 動態資料需區分影片量測值、研究假設、動畫藝術參數，不能把示範數字冒充真實速度。

**第二階段：行為**
- 躲藏、探索、休息、攝食與環境選擇；根據可靠來源建立物種／個體條件，而不是固定機率胡亂切換。
- 日夜活躍度不設定為「永遠夜行」：不同研究、季節與飼養條件可能有差異；需要依資料建立環境依賴規則。
- 避免擬人化，沒有資料的壓力、健康或社交行為先留空。

## 2. 顏色與紋路：必須拆成不同層

1. **體色／色素機制**：決定可能的色素表現；不是用任意 RGB 取代真實色型。
2. **花紋拓樸**：斑塊、條紋、斑塊融合等空間分布方式。
3. **個體差異種子**：在特定品系與合法的外觀範圍內生成少量形狀差異，反覆載入不變。
4. **遺傳模型**：單獨建置，有文獻或可信繁殖紀錄的性狀才建立基因型／遺傳規則；不可把色型名稱一律當作單一顯隱性基因。
5. **個體外觀呈現**：動態彎曲時，花紋須貼附身體而非浮在畫面座標；皮膚、頭部、腹部可分層遮罩。

### 第一批色型候選（僅為分類參考）
- Normal（野生型／原色）：橘色基底，背側紅橘斑塊及輪廓，腹側格紋。
- Amelanistic（缺黑色素／白化型）：有發表 OCA2 相關研究；不是所有低黑色素表現都可以混成同一性狀。
- Anerythristic（缺紅色素型）：名稱與常見外觀可先列候選；具體遺傳細節需進一步核對。
- Motley／Stripe：已有 CLCN2 相關研究，花紋與腹側外觀均有差異；不能只是換顏色濾鏡。

**與晶脈夜蜥的分界：** 玉米蛇應使用現實色素／花紋資料；晶脈夜蜥保留為後期傳說級原型，現在不做虛構特徵實作。

## 4. 實作狀態與驗收

- 目前新增**純資料校驗規格**與**可持久化的外觀生成參數容器**；正式基因配對、實體動畫、行為 AI、捕食與飼養環境尚未開發。
- 運動動作限制與轉換依現有 `src/ohm-core/reptile-motion.mjs`，不強迫所有蛇種共享完全相同習性。
- 不直接修改正式飼養箱或雲端存檔。
- 先用測試資料確認外觀種子不變，再完成中心線曲線、運動與皮膚紋路映射；等實際影片數據驗證後，才能稱為具生物依據的動作。

## 7. v0.4 外觀模板與像素紋理 A/B 測試（2026-11-08）

使用者提出「玉米蛇仍需要調整，我們現在可以怎麼做」。本輪採**保留原有 v0.3、另建 v0.4 獨立對照頁**，避免回歸風險與影響正式存檔：

- **新展示頁**：`corn-snake-lab-v04.html`。可直接與 `corn-snake-lab.html` 對照。操作功能：五種原有色型視覺候選、速度、暫停、重新生成個體種子，加上**像素鱗片細節開關**及**少量底材粒子開關**。後者預設關閉，僅為視覺回饋，非生物自身發光。
- **新純資料模組**：`src/ohm-core/corn-snake-visual-template.mjs` 定義蛇身頭到尾的漸細輪廓、隨個體固定 seed 產生的局部像素小點資料，沿用既有 `makeCornSnakePattern()` 斑紋位置。每次渲染僅沿蛇身局部座標取樣，沒有把每個像素變成獨立的 Phaser 物件。
- **動態不打掉重練**：仍使用 v0.3 的 `generateSnakePose()`，但 v0.4 將速度積分到演示時鐘，避免使用者中途調整速度時，由於「總時間 × 新速度」導致位置不連續的跳躍。
- **品質限制**：目前是 Canvas 程序化外觀與小像素細節試驗，**不是已完成的精緻像素 sprite atlas，也未實作真正鱗片實測排列、動態碰撞、自由路徑、物種遺傳或攀爬**。粒子效果不表明真實蛇必然揚起可見灰塵。
- **測試**：擴充 `tests/corn-snake-motion.test.mjs` 驗證程序貼圖同 seed 固定、不同 seed 不同、細節在局部身體座標範圍內、輪廓由肩部至尾部漸細、錯誤參數拒絕。

### 接下來用手機比較的六項

1. 先看 v0.3，再看 v0.4；判斷**頭身比例、尾巴粗細**是否變自然。
2. 開／關「像素鱗片細節」：花紋是否更精緻，而不是變髒或噪點過多。
3. 使用「生成新的個體紋路」，看兩隻的差異是否合理；重新進入頁面會回到預設種子 1049，**不代表正式存檔功能**。
4. 轉彎時看斑紋與身體是否錯位、外溢、消失。
5. 調整速度時看是否突然瞬移、斷裂或卡住。
6. 最後開啟「少量底材粒子」，觀察是否自然且沒有造成手機發燙或卡頓。
