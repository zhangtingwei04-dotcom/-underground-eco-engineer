# 玉米蛇（Pantherophis guttatus）｜首個真實爬蟲動態與個體花紋研究原型 v0.1

- 日期：2026-11-08
- 狀態：**確定首個真實爬蟲開發樣本；資料模型與科學來源建檔，不代表動畫／遺傳／飼養系統已實裝**
- 物種 ID：`pantherophis-guttatus`
- 物種類型：現實生物；與未來傳說級晶脈夜蜥的虛構資料分開。
- 優先理由：蛇身連續曲線運動、觀察／攀爬／藏匿等真實行為，以及豐富但需要科學約束的色素與花紋變異。

## 1. 動態系統先做什麼

**第一階段：運動**
- 蛇體中心線及分段姿態資料結構。
- 停止／靜止、側向波動前進、轉向、進入躲避處、環境碰撞。
- 攀爬或狹窄空間運動作為後續研究項目，不能未經驗證就把所有蛇類運動模式放入同一物種配置。
- 動態資料需區分影片量測值、研究假設、動畫藝術參數，不能把示範數字冒充真實速度。

**第二階段：行為**
- 躲藏、探索、休息、攝食與環境選擇；根據可靠來源建立物種／個體條件，而不是固定機率胡亂切換。
- 日夜活躍度不設定為「永遠夜行」：不同研究、季節與飼養條件可能有差異；需要依資料建立環境依賴規則。
- 避免擬人化，沒有資料的壓力、健康或社交行為先留空。

## 2. 顏色與紋路：必須拆成不同層

1. **體色／色素機制**：決定可能的色素表現；不是用任意 RGB 取代真實色型。
2. **花紋拓樸**：斑塊、條紋、斑塊融合等空間分布方式。
3. **個體差異種子**：在特定品系與合法的外觀範圍內生成少量形狀差異，反覆載入不變。
4. **遺傳模型**：單獨建置，有文獻或可信繁殖紀錄的性狀才建立基因型／遺傳規則；不可把色型名稱一律當作單一顯隱性基因。
5. **個體外觀呈現**：動態彎曲時，花紋須貼附身體而非浮在畫面座標；皮膚、頭部、腹部可分層遮罩。

### 第一批色型候選（僅為分類參考）
- Normal（野生型／原色）：橘色基底，背側紅橘斑塊及輪廓，腹側格紋。
- Amelanistic（缺黑色素／白化型）：有發表 OCA2 相關研究；不是所有低黑色素表現都可以混成同一性狀。
- Anerythristic（缺紅色素型）：名稱與常見外觀可先列候選；具體遺傳細節需進一步核對。
- Motley／Stripe：已有 CLCN2 相關研究，花紋與腹側外觀均有差異；不能只是換顏色濾鏡。

**與晶脈夜蜥的分界：** 玉米蛇應使用現實色素／花紋資料；晶脈夜蜥保留為後期傳說級原型，現在不做虛構特徵實作。

## 8. v0.5 休息、轉頭與探頭的自然活動節奏原型（2026-11-08）

### 使用者回饋與目標

使用者測試 v0.4 後表示比 v0.3 有進步，但希望**玉米蛇不會持續移動，也會停頓，偶爾轉頭朝畫面觀察一下、短暫探頭**，像生物自行生活的自然節奏。這不等於動物具備人類式「發呆」「理解玩家」的心理。

### 已製作（獨立 demo；不修改既有 v0.3/v0.4）

- 新頁：`corn-snake-lab-v05.html`
  https://zhangtingwei04-dotcom.github.io/-underground-eco-engineer/corn-snake-lab-v05.html
- 新純函式：`src/ohm-core/corn-snake-activity.mjs`；提供 `sampleCornSnakeActivity(seconds)`、`applyCornSnakeHeadGesture(pose,activity)`，與 Phaser/Canvas/DOM 解耦。
- v0.5 每個**示範循環約 52 秒**，包含：**爬行 → 停下休息 → 緩慢轉頭 → 朝畫面方向停留觀察 → 轉回 → 爬行 → 小幅探頭 → 停頓 → 再爬行**。這是測試用劇本，不是玉米蛇的實測時間比例或生態行為機率。後續正式系統需依環境、個體、活動時間與科學來源建立非固定循環。
- 在休息、轉頭及探頭時，透過 `motionTime` 凍結整條身體的位移，只讓頭部與靠近的頸部在有限範圍內變形。花紋仍沿用 v0.4 個體 seed，底材粒子只在爬行時產生。
- 保留五種色型**美術候選**、局部像素細節、粒子開關、速度／暫停／重抽花紋；新增「自然停頓與探頭」切換及「看停頓」「看轉頭」「看探頭」快速預覽鍵，避免用戶必須等 30 秒才能看到指定動作。
- v0.4 與 v0.3 網頁保留，可以 A/B 對照。新 `tests/corn-snake-activity.test.mjs` 檢查：狀態時序、停頓身體不位移、頭部轉向幅度漸變、探頭往返、52 秒循環接續時 motion time 不跳動、尾部不被頭部動作拉動、輸入檢查。
- `.github/workflows/ohm-core.yml` 已加新測試步驟與路徑監測。

**重要限制**：這是**可玩的動作展示稿**，不是完成的自然動物行為 AI、認知模型、實際身體肌肉／接觸力學或已校正的生物活動預算。「朝畫面方向轉頭」只是一個自然姿態的美術解釋，不代表牠「看見玩家」或意圖互動。尚無真正的自由尋路、障礙物碰撞、攀爬、呼吸量測或正式像素 sprite。

### 驗收要點

1. 觀察停頓時身體、斑紋與尾巴是否真正靜止；按鈕可直接切換示範。
2. 頭轉向畫面後是否留有明顯的安靜時間，轉回時是否順暢、沒有突然翻轉。
3. 探頭時頭頸是否小幅移動、身體其他部分仍穩定，沒有不自然拉伸、壓縮或花紋滑動。
4. 中途改速度、手動暫停／繼續、關閉自然節奏後再打開，都不應造成主畫面功能或存檔問題。
5. iPhone 直式／橫式及桌面各測一次。若視覺效果太規律或失真，調整示範時序與姿態，不捏造真實物種的固定活動比率。

**沒有更動正式遊戲 Scene、舊兩版試驗頁、Supabase／Cloudflare 或玩家雲端存檔。**
