# 生態模擬範圍與遊戲主次架構

**決策日期：2026-11-07**  
**狀態：核心方向已確認；細部生態參數與實作方案待後續規劃。**  
**本文件記錄設計方向，不代表相關功能已完成程式實作。**

## 1. 核心決策：飼養箱是完整生態模擬的核心單位

《鱗片與種子》將完整、可持續觀察與研究的生態模擬集中在玩家能直接管理的飼養箱內。每個飼養箱作為獨立的生態模擬單位，讓玩家能透過照顧、觀察、調整環境與研究，理解箱內生物及環境之間的關係。

不再以整個地下世界都必須持續運作完整生態系統作為開發前提。這項調整是模擬範圍與資源配置的聚焦，不代表地下世界缺乏生態、野生物種或自然環境。

## 2. 遊戲內容的主次分明

### 2.1 主要玩法：飼養箱生態（完整模擬）

依遊戲階段逐步建立並擴充下列面向：
- 動物個體、物種需求及符合真實習性的行為。
- 植物生長與環境需求。
- 底材、水分、排水與有機物狀態。
- 分解者及土壤微生物的群體作用；不要求模擬每一隻微小生物。
- 溫度、濕度、光照、通風等環境條件。
- 上述因素之間可觀察、可研究且有意義的交互影響。

各項內容應循序實作，先確保核心飼養玩法穩定、容易理解且真正可玩，再增加複雜度。不得為追求模擬細節而犧牲手機與桌面裝置的穩定性、操作體驗或遊戲可完成度。

### 2.2 輔助內容：地下世界、野生生態與探索（簡化呈現）

保留地下世界的地理、棲地、物種分布、生物知識、野生動物及探索遭遇等內容。野生生物可以透過預設資料、場景配置、條件式事件或必要的簡化狀態呈現；不要求所有地區的野生族群、食物網、遷徙、繁殖與死亡都持續進行完整即時模擬。

簡化不等於刪除世界生態內容。地下世界仍應有可信且連貫的自然環境背景，只是將昂貴的動態模擬集中在玩家主要操作的飼養箱。

### 2.3 輔助內容：研究站、NPC 與地下文明生活（依重要性分級）

研究站、NPC 自主生活、社交、工作、家庭及世界事件仍可保留，但依角色與事件重要性採取不同模擬深度。重要角色及重要事件可呈現較完整內容；一般角色與背景生活採簡化、低頻更新或事件摘要。此分級原則與既有 NPC 設計方向一致。

## 3. 複雜度與資源配置原則

- **主次分明：** 玩家主要時間、互動深度與開發資源優先投入飼養箱生態；地下世界及背景生活提供探索、敘事、研究與世界感，不與核心玩法爭奪同等模擬成本。
- **先可玩，再擴充：** 先完成小而穩定、能讓玩家理解並享受的生態循環，再逐步增加物種、環境變數及交互作用。
- **以實際遊玩價值決定複雜度：** 只有能帶來可觀察、可理解或可操作的遊戲價值時，才增加模擬細節。
- **低成本背景呈現：** 非核心世界內容優先使用資料、事件、摘要與低頻結算，不建立沒有必要的全域即時模擬。
- **跨系統共用資料：** 物種知識、棲地資料及研究資料可由飼養箱、圖鑑與探索系統共用，避免重複建立互不相容的資料。
- **穩定優先：** 若某項模擬造成手機或桌面效能下降、卡死、維護負擔過大或主要玩法難以完成，應簡化、延後、暫停或移除，而非為了保留複雜功能犧牲遊戲品質。

## 4. 技術方向與尚待規劃事項

以下是後續可評估的技術方向，並非已確認的具體實作規格：
- 將生態狀態計算與畫面上的動物行為表現分層，避免畫面動畫直接決定生態數值。
- 先採可測試、可預期且效能可控的規則／狀態系統，再視需要擴充行為決策能力；不把生成式 AI 當成生態計算的必要依賴。
- 評估離線進度、時間結算頻率、單箱運算上限、同時活動的飼養箱數量及裝置效能預算。
- 物種相容性、共養、繁殖、疾病、捕食及分解作用，須依真實物種需求逐步設計，不以抽象的「生態平衡」機制取代生物學差異。

目前尚未確認離線模擬的具體規則、每個飼養箱的運算頻率、完整物種清單、數值模型及各階段開發時程，不得將提案直接視為已定案規格。

## 5. 開發驗收方向

每次增加生態複雜度時，應先確認：
1. 玩家是否能觀察並理解變化原因？
2. 變化是否符合對應物種及環境的基本生物學需求？
3. 這項細節是否真正改善照顧、觀察或研究玩法？
4. 在目標手機與桌面裝置上是否仍能穩定運作？
5. 若移除或簡化此細節，是否仍能保留主要遊玩價值？

若效能或維護成本與遊玩價值不成比例，優先簡化。

## 6. 物種背景研究與現實／虛擬資料制度

物種研究採現實物種與歐姆原創虛擬物種雙軌管理。現實物種以可靠現實科學資料為依據；虛擬物種必須清楚標示虛構身分，記錄其歐姆世界分布，並以現實生物學與生態學作為棲息地、生態角色及行為設計基礎。若沒有相符的現實物種紀錄，明確標示「目前沒有相關現實物種紀錄」，不捏造現實學名或分布，未來可依研究與世界觀需要補充。現實世界分布與歐姆世界分布必須分開保存；資料來源、合理推論、遊戲簡化及世界觀創作也須清楚區分。

詳細資料制度見 [SYSTEM_DESIGN_SPECIES_BACKGROUND_RESEARCH.md](./SYSTEM_DESIGN_SPECIES_BACKGROUND_RESEARCH.md)。本節只定義研究與設計原則，不代表物種資料庫或圖鑑功能已實作。


## 7. 特別生存地的生態模擬邊界

- 特別生存地是地下世界的大後期探索內容，主要承載歐姆原創虛擬物種及其特殊棲地；不取代飼養箱作為完整生態模擬核心的定位。
- 特別生存地需有可信的環境條件、物種分布與生態關係，但優先採場景配置、物種資料、探索紀錄、條件式事件及必要的簡化狀態呈現。
- 不要求每個特別生存地都進行全時、全物種、完整食物網即時模擬；只有確實能改善探索、觀察或研究體驗的互動才增加模擬深度。
- 區域棲地與生態仍以現實生物學及生態學為設計基礎；明確超出現實知識的部分標示為歐姆世界觀創作。
- 開放順序、地圖規模、事件密度及同時呈現的生物數量，需以手機與桌面效能及實際可玩性評估。


## 8. 每週探索環境的低負擔呈現

每週探索環境採「一個符合玩家目前研究等級的環境，加上數個隨機環境」的混合方向。這些環境屬地下探索內容，不要求每個生成地點都進行完整即時生態模擬；優先以環境資料、場景配置、物種分布、條件式事件及必要的簡化狀態呈現。

玩家可自由選擇探索、暫緩或整週完全不探索。略過不應造成研究進度、資格、關係或資源懲罰，也不應清除已保存的探索成果。特殊環境可依研究認證、特殊通行證、官方許可或必要裝備限制進入。每週生成的數量、保存期限、刷新方式及通行證細節仍待規劃；穩定遊玩與不強迫登入優先。
