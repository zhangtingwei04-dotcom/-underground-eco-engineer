## 圖像直接可見的內容

畫面是一張橫向長幅、左右大致對稱的蛇皮圖案式平面視圖：

1. **中央縱向帶狀結構**：自上至下排列較寬、邊緣近乎圓角梯形的淺米色大鱗片。它**視覺上類似**蛇腹側的寬大腹鱗（ventral scutes），但圖片不是有物種比例尺的生物學標本，不能確定它是正確的蛇腹鱗細部。
2. **中央帶狀兩旁**：一圈較大型棕色至深褐色的多邊形鱗片，越外側逐步出現相對較小、較密集的魚鱗／菱形／多邊形格網。
3. **側翼大型花紋**：黑色與深褐色的不規則斑塊及米黃色碎裂紋樣，疊在細密格網上；左右近乎鏡像，但細節並非每格完全對稱。
4. **色彩與輪廓**：米黃、淺棕、暖褐、深咖啡、黑色等有限色階，加上強烈的深色輪廓線，呈現插畫化、可重複的表面裝飾感。
5. **非自然攝影**：線條粗細和鱗片邊界一致性呈現圖案化效果；畫面未顯示頭、軀體邊緣、實際曲面／動態、自然光照、可驗證的物種鑑定特徵。

## 對《鱗片與種子》的原創像素蛇模板之用途

建議技術分層：
- `ventral_scute_band`：腹面寬鱗片獨立參數，受物種、體段及可見角度控制；不能只是另一個深色重複圖樣。
- `lateral_scale_field`：側面鱗片尺寸、方向、排列，可隨體幹周向 `u` 和沿蛇身 `s` 的局部座標變化。
- `large_pattern_regions`：大斑紋獨立於微鱗片排列，不要將「大色塊」畫死在世界座標，蛇轉彎時需貼在體表一起彎。
- `palette_material`：底色／背部／腹部／側面各自由物種專屬規則決定，之後才依光源繪製高光、陰影。
- `pixel_lod`：近景圖鑑可看見細鱗輪廓；一般飼養箱視角以大色塊和少量細節為主，避免 3840 px 貼圖直接縮小導致噪點與頻閃。
- `seeded_texture_cache`：使用原創演算法與固定個體 seed 建立快取紋理，以免每一幀都重新生成數千塊鱗片。
