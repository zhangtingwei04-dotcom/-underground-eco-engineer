# 研究先蒐集、後統整：新手易懂與逐步實作原則

日期：2026-11-08  
遊戲：《鱗片與種子：地下生態物語》  
狀態：**使用者正式確認的長期工作方式**，目前是研究與編輯流程規則，尚未新增遊戲功能。

## 核心方向

**先蒐集與保留資料，再逐步統整；玩家看到的文字保持簡單；實作從基本功能開始，日後再漸進增加細節。**

不用每看到一篇論文，就立刻設計一整套機率、複雜生態系統或長篇遊戲說明。研究庫可以保存完整且專業的原始資訊；玩家介面不必同時顯示所有細節。

### 研究階段一：先放進資料庫

優先順序維持：
1. 西部豬鼻蛇、玉米蛇。
2. 其他會飼養的爬蟲。
3. 直接關係爬蟲照護的底材、植物、微環境。
4. 其他生態、礦物、地質等後期內容。

新來源可以是原始研究、獸醫與官方指南、專業飼養網站、台灣／國外爬友公開經驗；先**依每一條主張**分別判別可信度、適用物種、可能風險，不以網站類型直接否定實用入門知識。

研究庫至少保存以下資訊（有資料才填，不得猜測）：

- **研究主題／物種：** 研究什麼，例如「豬鼻蛇挖洞」、「玉米蛇攀爬」。
- **來源：** 網頁或論文標題、連結、作者／機構與日期。
- **發現：** 用中文記下來源實際說明的內容（細節、樣本數、條件、測量單位）。
- **限制：** 是野外還是圈養、幼體或成體、哪個地區、是否只是個別飼主經驗。
- **判別：** 已驗證、專業實務建議、待查證、存在爭議／不採用。
- **存放狀態：** 只有連結、讀到摘要、讀到全文、是否實際取得原始檔；授權是否允許再利用。

**資料庫可以先收集再統整，但不能先把互相衝突或高風險的說法寫成已證實的事實。** 相同 DOI／文章來源要去重，內容不一致時保留來源差異，不擅自合併成單一數值。

Cloudflare D1 `scales-seeds-biology-research` 負責研究資料**索引與重點摘記**；CSV、PDF、照片、影片等大型原檔需獨立、合法備份並標記狀態，**不能因 D1 有檔名就視為已備份**。

### 研究階段二：等資料足夠再統整

同類資料累積後，再依「物種 → 飼養／行為／健康等主題 → 生命階段與環境 → 來源可信度」整理。

統整時才解決：
- 相同概念哪些可歸納成**新手共通知識**；
- 哪些數值可能因物種、體型、環境、測量位置而改變；
- 哪些是社群個案、研究限定條件或真正有爭議的主張；
- 哪些發現適合加入圖鑑、教學或行為系統。

並非每蒐集一筆資料都需要立即製作完整研究報告或重設遊戲程式。

### 玩家文字分層：先簡單，再深入

**最基本畫面：** 1–2 句繁體中文，親切、準確、能理解，不堆 DOI、統計、艱深術語。  
**想知道原因：** 點開「為什麼？」可多看 2–4 句簡短解釋。  
**深入研究頁：** 顯示真正的研究細節、物種／年齡限制、來源與待驗證之處，讓有興趣的玩家自行閱讀。

**示範，非新研究結論：**

- 基本：「豬鼻蛇喜歡在適合的底材裡挖掘，也需要可以安心躲藏的地方。」
- 詳細：「研究觀察到部分年幼西部豬鼻蛇更常待在設有可挖掘底材和其他豐富設施的環境。不同個體的活動方式可能不一樣。」
- 研究來源：`https://doi.org/10.3390/ani12233347`；16 隻年幼個體，實驗同時更動數種環境條件，不能說每一條蛇或每種底材都會有相同效果。

**文字規則：** 用「可能」、「常見」、「在某研究中」精確表達不確定性，不把研究樣本當普遍真理；健康、安全、照護規範若具爭議，不用簡化為錯誤的絕對指令。

### 研究階段三：慢慢增加遊戲複雜度

- **第一步：** 先完成好懂的物種介紹、基本環境布置、少數有根據的行為（探索、躲藏、挖掘／攀爬）與觀察日誌。
- **第二步：** 隨資料增多再加入不同環境、進食後狀態、生命階段、個體差異與條件式行為。
- **第三步：** 才考慮更精細的研究報告、繁殖／進階生態關係，以及以後的植物、礦物和特殊地下場景。

**重要：** 不是蒐集資料愈多，程式就必須愈重。保留研究深度，但只把對玩家體驗有幫助、效能可承受的部分實作。遊戲維持慢生活、不強迫每天登入，不因照護知識多就增加瑣碎負擔。

## 每次後續研究的最簡回報

- **這次收了什麼：** 物種、資料主題、幾筆真正新增／更新的資料。
- **目前可信度：** 已驗證／待核對／有衝突，並簡述原因。
- **還缺什麼：** 只列最重要的待查項目。
- **存到哪裡：** GitHub 研究文件或 D1 索引；清楚說明是否真的取得／備份原始檔。

不需要每次把全部論文內容搬到玩家畫面，也不需要逐次決定遊戲設計細節。

## 與既有研究規則的關係

- 取代先前「蒐集到資料後就立刻完整統整／實作」的作業傾向；先保存與逐則判別，**大規模統整後置**。
- 不變更已確認的「爬蟲優先、完整生態後續」「來源逐則核對」「新手有用的飼養經驗可以採納」等設計決策。
- 此次僅更新研究工作流程文件；**不修改遊戲程式、玩家存檔、D1 資料表結構，也不宣稱原始檔已備份**。

## 玩家學習入口更新（2026-11-08）

原先「玩家先看到一至兩句簡單知識」的原則維持；**具體主要載體改為 NPC 依日常情境自然提及的小知識**。研究人員可先蒐集完整論文／飼養經驗，再挑出可安全教給新手的簡短句子；有爭議者保留「可能／尚未確定」的正確語意。

圖鑑主要供玩家快速查閱名稱、圖、少量習性、已觀察紀錄；深入研究與 DOI 仍存於後端資料庫與可選展開頁，**不要讓玩家必須閱讀長篇百科才能遊玩**。

整體 NPC 性格／生活仍優先於教學：適合的交談自然順帶一則知識，特殊情緒／重大劇情可以完全不談科普。具體請見 [NPC 自然聊天學習與極簡圖鑑](../SYSTEM_DESIGN_NPC_AMBIENT_LEARNING_AND_SIMPLE_FIELD_GUIDE.md)。
