## 累積數量與重要限制
此前驗收的 S1T1 和 S1T2 M.csv 分別為 8,193 和 14,100 影格；本批再增 37,757，**目前已收到五個 M.csv 動捕檔，合計 60,050 個時間影格**。這些是五段試驗紀錄，**不是 60,050 次獨立生物行為實驗**。

- S1T3、S5T2、S5T3 使研究涵蓋至少兩種原始個體／試驗標識（S1 與 S5），但不能僅憑檔名判定物種差異或實際個體總數。
- 缺失影格和 marker ID 分段需先清理；目前沒完成解剖身份辨識及力量／動作事件同步，不應直接輸出蛇身骨架。
- 研究數據作為科學參考儲存。先建立真實生物研究資料庫與高真實度參考模型，後續才以手機／電腦實測效能決定正式遊戲的動畫簡化策略。
- 不公開提交第三方原始大型 CSV，也不修改現有 Phaser 正式遊戲及玩家存檔。
