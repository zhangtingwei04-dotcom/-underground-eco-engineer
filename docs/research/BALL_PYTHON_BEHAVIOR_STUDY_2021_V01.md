# 球蟒 Python regius — 行為與飼養環境研究摘錄 v0.1

- 建立：2026-11-08
- 來源：Hollandt T, Baur M, Wöhr A-C (2021). Animal-appropriate housing of ball pythons (Python regius)—Behavior-based evaluation of two types of housing systems. PLOS ONE 16(5): e0247082.
- DOI：https://doi.org/10.1371/journal.pone.0247082
- 研究材料：使用者上傳公開 PDF `journal.pone.0247082.pdf`；文章 CC BY，研究引用需標示出處。
- 性質：**已閱讀之論文行為資料**，不是原始逐幀運動數據，也未接入正式遊戲。
- 分界：以下數字及分類只描述該研究觀察結果，不是遊戲的物種通用機率、飼養法規或遺傳學定律。

## 一、研究設計與限制
- 35 隻球蟒（25 雄、9 雌、1 幼體性別未明）。
- 先在傳統 rack system（個別抽屜）飼養，至少八週後同一批動物在有豐富設備的 terrarium 飼養；比較不同環境下可表現的行為。
- 行為每 10 分鐘記錄一次，每日 144 個單位，各飼養條件觀察 5 日。
- 設備完整生態箱提供底材、躲避處、攀爬物、泡水盆、加熱／照明、活植物和不同高度的活動空間。
- **限制**：同一批動物依固定先後順序觀察，環境設備與可用空間等多種因素同時不同；本研究不代表任意野外球蟒、所有品系或精確個體行為機率。研究結果以統計觀察頻率呈現，而非逐影格姿態資料。

## 二、論文 Table 2 行為分類（第 10 頁）
- L1 crawling forward：向前爬行；含側向波動與直線運動或兩者結合
- L2 moving backward：身體或部分身體向後推移；不等同於持續真正倒著蛇行
- L3 lifting front body up：抬高前段身體
- L4 climbing：至少一半身體離地的攀爬
- L5 burrowing：至少頭部至眼部進入底材
- L6 moving head：移動頭部（單獨分類）
- E camera-directed exploration：朝攝影機探索（研究特定情境）
- C1 basking：至曬背點停留
- C2 bathing：進入水盆並停留，不把「穿越水盆」當作泡水
- C3 resting in hide：在有側壁接觸的躲避處休息
- C4 resting outside coiled：躲避處外盤繞休息
- C5 resting outside stretched：躲避處外伸展休息
- A defensive/aggressive behavior：防禦／攻擊
- F drinking：飲水
- O1 yawning：張口／打呵欠
- O2 mouth pushing barrier：用口鼻推擠飼養空間邊界
- O3 pathological behavior：異常神經／運動表現（wobbling、stargazing）

論文稱分類 17 種；Table 2 中部分以大類而非獨立細項呈現。勿把分類碼數量直接等同「可播放動畫數量」。

## 四、活動時段與環境
- 論文分三個觀察時段：P1 16:00–23:00、P2 23:01–次日 07:00、P3 07:01–15:59。
- 在研究生態箱環境裡，向前爬行、攀爬、掘土等活動在 P1 更明顯；這並不表示所有球蟒在其他時段完全不活動。
- 論文記錄以生態箱能否提供行為機會（攀爬結構、可挖掘底材、水盆、曬背點）為重要條件。
- 研究在有 UV 的曬背點觀察到色素正常球蟒平均約 144±13 分鐘／日的使用時間，白化球蟒約 10±2 分鐘／日；這是該研究樣本觀察，不能直接作為照明配置或所有白化個體的通則。

## 五、動物福利與風險
- 論文中 rack 空間更常出現沿壁推擠等行為，研究者指出不應用狹小環境單純追求方便管理。
- O3 屬於異常行為，不該作為罕見外觀的獎賞動畫或好玩特效。
- 本文指出部分 Spider 類型在研究中出現 wobbling；**不得將其浪漫化或鼓勵選育有害形態**，亦不能僅根據外觀直接診斷現實動物。
- 未來正式遊戲對溫溼度、UV、安全設施和適用尺寸的設定，須核對更多可靠物種資料與專業建議；本研究飼養設置是實驗情境，不是全物種通用參數。

## 六、Ohm Core 整合計畫（未實作）
- 建立 `python-regius` 真實物種行為詞彙／來源紀錄，和玉米蛇的運動數據分開。
- 核心依據環境可用設施與生理需求來決定**可進入的行為狀態**；例如沒有攀爬物，不能在空中播放攀爬動畫。
- 行為可用條件：`ground`, `hide`, `climbable`, `burrowable_substrate`, `bathing_basin`, `basking_area` 等示意欄位；具體判定後續建立。
- 表現層由 Phaser 或替代 Renderer 負責。核心保持與 UI、時鐘、儲存分離。
- 個體花紋與健康／生理資料分離；研究標示 `observed`、`estimated`、`illustrative`，防止把遊戲數值當作科學測量。
- 下一步適合建立球蟒行為分類資料 JSON + 驗證測試；**不急著做違背生態資料的動態特效**。
