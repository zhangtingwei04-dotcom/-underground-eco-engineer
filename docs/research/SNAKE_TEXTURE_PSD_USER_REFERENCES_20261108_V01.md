## 圖像 T1：橘黑高密度皮紋

**可直接觀察**：大幅橘色、淺米色、深棕／黑色相間的蛇皮風格表面圖樣。可見大塊不規則的深色和淺色斑塊，內部覆蓋細密、大小各異的鱗片狀格紋。色階、深淺紋理同時存在；圖樣並非一條蛇的連續 3D 體表貼圖。

**對原創像素生物的技術啟示**：
- 在蛇身模板上，分離 `base_color`（底色）、`large_marks`（大斑塊）、`scale_microtexture`（小鱗片）、`light_response`（光照）。
- 用局部軀體座標而不是整張螢幕座標固定紋理，蛇轉彎時花紋必須跟著體表。
- 近距離圖鑑可保留局部鱗片細節；遊戲日常視角應降低微紋理密度，避免變成噪點。
- **觀察圖樣不等於確定是玉米蛇**：不可從素材外觀建立 `Pantherophis guttatus` 的真實斑紋基因、無鱗品系、腹鱗排列或可靠物種鑑定。

**限制**：截取的平面圖樣不保證無縫貼圖（seamless）、可用於骨架 UV 連續映射或可直接用於移動中蛇身。大圖縮小會有像素頻閃／摩爾紋風險；不能當現成遊戲貼圖直接貼上。

## 圖像 T2：米黃棕黑規則菱形鱗片

**可直接觀察**：以淺米白、金黃、棕、深褐的規則菱形單位重複鋪排，菱格輪廓清楚、填色分布形成較大連續紋樣。它是風格化的平面圖樣，不應當成某一種蛇的實際腹鱗／背鱗細部解剖紀錄。

**對原創像素生物的技術啟示**：
- 可研究**程序化重複格網**：先生成局部的鱗片中心排列，再以低解析度像素區塊控制色彩。
- 程序化紋理中的 `scale_cell`、`color_region` 與 `body_mask` 應獨立，才能給不同物種使用**不同的實際鱗列規則**，而不是所有蛇貼同一張菱形皮。
- 在低倍率 UI 或遠景，可先保留大型花紋／對比；只有鏡頭夠近才露出格網；減少 aliasing 與效能損耗。
- 使用固定 `individual_seed` 生成個體紋路，再緩存到紋理 atlas；**不等於模擬了真實基因遺傳**。

**限制**：規則菱形不等於每隻蛇真正同樣大小、形狀或排列的鱗片；實際玉米蛇背側與腹側鱗片形態不同，不應只把 T2 格網畫滿背腹。

## 附帶的 `ibaotu.doc` 與素材授權注意

兩個 ZIP 附帶的 Word DOC 文字內容相同，開頭標示這是「包圖網平台上提供的廣告設計模板」，稱原創作品及預覽圖受著作權法保護，並要求「未經許可」不得擅自使用。文件也提到模板可結合使用需求修改後使用，**但這段一般說明沒有明確列出這兩個 PSD 在本遊戲中的授權範圍、會員身分、使用者取得方式及分發／轉售條件**。

**結論**：目前**不能因為使用者提供 ZIP 或一般 DOC 說可修改模板，就認定有無限制的遊戲商業使用許可**。在確認合法可使用的具體授權前：
1. 只研究通用的鱗片生成／遮擋／顏色層次方法，不把原 PSD/圖案裁切、重繪描摹或轉換為遊戲資產。
2. 公開 GitHub 只存這份原創文字研究筆記，不上傳 PSD、壓縮包、DOC、衍生預覽或第三方作品圖。
3. 如將來確實要使用原作品作為正式美術素材，需要確認購買紀錄／授權條款是否允許遊戲、商業發行、修改後再分發與源文件公開；**用自主生成的原創紋理取代，是現階段成本與風險較低的方案**。

## 與既有動態及美術架構的銜接

現況：`src/ohm-core/corn-snake-visual-template.mjs` 以個體 seed 生成蛇身細節候選，`corn-snake-lab-v04.html`／v0.5 有不同顏色／紋路示範。

**下一步可小步實作**：
- 在 v0.6 或之後版本，視效能額外加入**自行撰寫的** `scale_grid` 演算法，按蛇身長度和體寬局部鋪排，不直接以完整 PSD 替代既有紋路。
- 細節 LOD：手機遠景只顯示大斑紋；近景圖鑑再分層顯示鱗片、反光和腹部不同圖樣。
- 蛇動態骨架與圖案應解耦：身體中心線、頭頸局部姿態變化，不使圖案滑動或瞬間跳格。
- 先測試**清晰、可重現、低成本的原創像素鱗片**，再決定是否需要較高解析度圖樣。
- **生物真實性優先**：不同蛇種由各自證據支持的形態和花紋模板決定，而非只換一張 PSD 或色盤。

**本批不是新影片**：先前六批累積 26 段錄影＋1 張像素蛇作品截圖；本批另外新增 **2 份 PSD 紋理參考 ZIP**，勿將其誤算成第七批影片。
