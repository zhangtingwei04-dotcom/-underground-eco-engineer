- 日期：2026-11-08
- 研究：Jurestovsky, D. J., Usher, L. R. & Astley, H. C. (2021), *Generation of propulsive force via vertical undulations in snakes*, *Journal of Experimental Biology* 224:jeb239020。https://doi.org/10.1242/jeb.239020
- 資料來源：https://doi.org/10.5061/dryad.6wwpzgmwt （整包約 659.69 MB）
- 已驗收附件：`ReadMe_Jurestovsky-VerticalUndulations-2021-JEB.xlsx`，`RT1_3_18_2020sp.csv` 至 `RT5_3_18_2020sp.csv`。
- 本批 **不是蛇類逐格骨架或蛇力學試驗，而是五次被動拖動尼龍繩的力感測器對照試驗**。此結論已由發表論文的方法與結果核實；不要把 `RT` 當成蛇個體編號。
- 目前只累積與驗證研究素材，**未導入遊戲、未重建動畫、未向公開 GitHub 上傳原始 CSV**。

## 已讀取的 README 檔案欄位單位
- 研究名稱與作者／實驗型態：Excel `ReadMe` 工作表。
- `Time`：秒，時間間隔 `0.001` 秒。
- `FZtotalSp`：左右感測器合併的側向（z 軸）力，**N（牛頓）**。
- `LFxSp`, `RFxSp`：左／右感測器的前後方向（x 軸）力，N。
- `LFySp`, `RFySp`：左／右感測器的垂直方向（y 軸）力，N。
- `LTxSp/LTySp/LTzSp` 及右側 `RTxSp/RTySp/RTzSp`：README「Unit」欄也填 Newtons，但名稱與說明均為 Torque；**物理上扭矩應有力乘距離單位，正式使用前需向原研究方法／原作者核實，不自行假設為 N·m**。
- CSV 的第 13 欄後是空白欄與第一列的 `Spline Values:` 相關文字註記，不應誤認為額外逐幀感測器欄。
- README 另有 **OptiTrack 蛇類動作捕捉**（另一類 `M.csv`）：`Frame`, `Time`, 接續三維標記點 X/Y/Z，位置 **公尺**，取樣 **120 fps**；每條蛇約 13–15 個標記點，但丟失／重建標記會造成額外的 marker ID。**本批 RT *.sp.csv 不是這類動作捕捉檔。**

## 研究意義與正確限制
論文方法說明：使用約 229 g、144 cm 的編織尼龍繩，在蛇類實驗用橫向木桿陣列上拖行，作為**無肌肉主動推進**的對照組。兩組六軸感測器安裝在其中一根木桿，原始力資料以 1 kHz 記錄，經 IGOR Pro 平滑。實驗結果：繩索產生剎車／摩擦作用，無主動推進力量；蛇則可透過垂直身體彎曲與接觸點取得推進。參考：https://pmc.ncbi.nlm.nih.gov/articles/PMC8278011/ 。

這批資料對《鱗片與種子》可作為**機制理解的科學對照**，用來比較蛇類有生命的主動動作與被動繩索運動。它不適合直接拿來決定玉米蛇姿態、游泳或捕食動畫，也不能取代真正的蛇體表三維點軌跡。
