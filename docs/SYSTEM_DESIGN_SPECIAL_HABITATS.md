# 特別生存地系統設計方向

**建立日期：2026-11-07**  
**狀態：核心定位與開放時期方向已確認；區域內容與解鎖細節待研究。**  
**本文件記錄設計方向，不代表相關地圖或功能已實作。**

## 1. 系統定位

特別生存地是歐姆地下世界中具有特殊環境條件、獨特棲地及生態組成的區域，主要承載歐姆原創虛擬物種及其生態故事。它不是單純的稀有物種商店或收集清單，而是玩家在深入探索後逐步認識歐姆特殊自然環境的地方。

## 2. 開放時期

- 特別生存地安排於遊戲大後期逐步開放。
- 玩家先熟悉飼養箱照護、基礎生態研究及一般地下探索，再逐步接觸特殊區域。
- 大後期開放的目的在於提供長期探索目標與世界觀揭露，不應以繁瑣或強制每日登入作為門檻。
- 實際解鎖條件、先後順序及進度需求尚未確認，需配合整體遊戲節奏設計。

## 3. 與虛擬物種的關係

- 歐姆原創虛擬物種原則上以特別生存地作為主要登場與探索場域。
- 每種虛擬物種都需記錄其歐姆世界分布；玩家可透過探索、觀察與研究逐步揭露資訊。
- 圖鑑清楚標示虛擬身分；沒有相符現實物種紀錄時，顯示「目前沒有相關現實物種紀錄」或適當等義文字。
- 虛擬物種的棲息地、生態角色、食物來源、行為與環境需求，仍以現實生物學和生態學作為設計基礎。現實類群僅作參照，不代表虛構物種等同該類群。
- 超出現實知識的特殊能力或環境機制，需明確標示為歐姆世界觀創作，並維持內部一致性。

## 4. 區域研究方向

未來可研究不同環境主題，例如深層地下森林、地熱洞穴、地下水域、特殊礦物洞窟或遠古封閉棲地。這些是候選研究方向，不是已確認的正式區域清單；每個區域必須先有合理的地質、氣候、水分、能量來源及食物網依據，再安排適合的物種。

## 5. 探索與保育界線

- 玩家可探索、觀察、拍攝、採集非活體研究資料或完成調查；具體互動依區域與物種特性決定。
- 發現物種不等於取得捕捉、帶離或飼養權。是否可帶離原棲地，需另依物種需求、保育規則、登記／許可制度及遊戲平衡決定。
- 特別生存地的物種分布、棲地資訊及保育狀態應有一致資料來源，避免圖鑑、探索和飼養系統互相矛盾。

## 6. 模擬與效能原則

- 特別生存地屬地下探索輔助內容，不改變飼養箱是完整生態模擬核心的定位。
- 區域生態優先使用環境資料、場景配置、物種分布、條件式事件與低頻摘要；不要求所有區域進行完整即時食物網模擬。
- 只有能帶來明確探索、觀察或研究價值的互動才增加複雜度。
- 手機與桌面效能、可理解性及穩定遊玩優先；必要時簡化區域規模、活動物種數量或事件頻率。

## 7. 尚待研究與確認

- 特別生存地的正式名稱、數量、地理位置及地圖連接方式。
- 各區域的地質、氣候、水文、能量來源與生態主題。
- 虛擬物種名單、分布、食物網及研究內容。
- 開放順序、解鎖條件、任務與探索節奏。
- 捕捉、帶離、保育許可及飼養規則。
- 區域內活動生物數量、事件頻率及效能預算。

以上項目需透過背景研究及後續核心設計逐步決定，不得把候選示例當成已定案內容。
