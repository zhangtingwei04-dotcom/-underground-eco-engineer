# 離線待同步存檔（2026-11-08）

已建立 `src/systems/offline-save-sync.js`，正式遊戲**尚未啟用**。
- 使用 IndexedDB 按已登入 Supabase 使用者 ID 分隔存放草稿，避免普通訪客進度與其他帳號混用。
- `stage(save, baseRevision)` 僅保存本機待同步版本；已有待同步版本時拒絕新資料覆蓋，避免丟失未同步內容。
- `inspect()` 查看待同步狀態，不回傳存檔內容。
- `checkSync()` 比對雲端版本，離線或版本分歧時暫停。
- `syncPending()` 必須明確呼叫，且須先確認雲端版本與本機基礎版本一致，再使用伺服器 revision check 上傳。成功後只清除符合當次 ID 的待同步草稿。
- 本功能暫無背景自動同步、衝突合併與跨裝置寫入；請勿稱其為完整備份。
- IndexedDB 是網站來源的本機儲存，使用者清除網站資料或瀏覽器可能刪掉它。後續需提供可辨識的存檔匯出檔案與獨立備份。
- 測試正式接入前，應確認初次建立雲端存檔、帳號切換、斷線、配額不足、斷電、不同裝置同時寫入等情境。
