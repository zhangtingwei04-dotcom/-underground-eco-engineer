# 《鱗片與種子：地下生態物語》｜地表新研究員：車站接待與住宿分支 V0.1

> 記錄：2026-11-11（台灣時間）  
> 狀態：**使用者提出的優先劇情構想，未完全拍板；具體演出與系統設計為候選提案，尚未實作。**

## 1. 使用者提出的五項要素

1. 角色是一位**比主角晚抵達歐姆的地表受派遣女性**；可將原創試作〈ひかりの庭〉（光之庭）作為她的角色歌候選。
2. **研究所向主角派發任務，請主角前往車站接她**。
3. 主角重返抵達歐姆的**同一車站**，自然回憶起當年自己剛抵達時的模樣。
4. 她會稱呼主角**「前輩」**，不必先決定兩人年齡或職級；可以先理解為主角較早在歐姆生活、具派駐經驗。
5. 接待後提供**住在主角住處／研究站生活區**或**她獨立找地方住**的分支。這是玩家可提出的安排，不代表 NPC 必須接受。

## 2. 與已確認開場相容

玩家初抵歐姆時從地熱纜車抵站，對歐姆語感到陌生，翻譯器在必要時啟動；完成入境、姓名登記並取得地圖、住址後，**自行**搭交通工具前往住處，途中因看見博物館而出於好奇停留。她晚到時由玩家接站，是不同的後續事件，**不改寫玩家第一次來時無人接待、自主探索的經驗**。

可在重訪車站時短暫帶出相同月台、廣播、出口或曾經不理解的標示，運用第一人稱鏡頭短暫閃回；建議可快速跳過或收錄到回憶相簿，不必重放整段開場，更不能替玩家強制指定當年一定孤獨或害怕。

## 3. 任務流程草案

- **委託通知**：玩家已安頓並熟悉基本生活後，地表研究機構／研究所透過研究終端寄來接站任務。抵達時間與實際研究職位仍待設定。
- **前往車站**：玩家透過既有公共交通到達地熱纜車車站；途中與到站時的相同場景，引出「這裡是我開始歐姆生活的地方」的短暫回憶。
- **新研究員登場**：她帶行李下車，尋找接待自己的研究員，初見可說「請問……您就是研究所提到的那位前輩嗎？」（**僅台詞草稿**）。稱呼可以伴隨關係自然變化，不強制永遠稱「前輩」。
- **入境與生活引導**：她照自身派遣契約完成姓名、身分等必要程序；主角可指路與解釋，但不越權閱讀身分資料，亦不自動公開玩家的地表原名。
- **住宿抉擇**：接待期間討論住宿，玩家提出是否可同住或協助找獨立住處，最終安排兼顧她的意願、房屋空間和研究所條件。
- **回歸自主生活**：無論住宿方式，她都有自己的工作、朋友、情緒、休息與研究計畫，不只跟著玩家走。

**慢生活保護**：任務可延後；若玩家選擇不接站，研究機構／她本人可以完成入境，稍後再相識，不因一次離線永久失去角色或扣除重要主線。若玩家主動接站，可有這段專屬回憶與對話；不強迫所有人都必看。

## 4. 住宿分支

### A. 玩家邀請她同住

- **邀請不是命令**。她可能接受、婉拒、先暫住再搬家，應依個性、當時信任、派遣與住宿安排合理決定。
- 需要適當私人臥室／休息空間；研究站的生態箱、照護室、危險設備與研究資料不能自動開放。玩家既有生物的福利、安全與環境條件不受同住犧牲。
- 可以新增自然日常互動：偶然一起吃飯、聊研究或各忙各的。她不是免費家務工、無條件助手或寵物保母。
- **同住不是戀愛判定**；是否可戀愛、是否願意發展感情仍由角色設計和雙方關係決定。

### B. 她找自己的住處

- 可以設定一個固定私人住處，依工作與個人喜好安排生活，玩家可以協助找房或提供生活資訊。
- 她可以拜訪玩家，雙方也能在研究站、商店、公共交通、圖書館或街上相遇。
- 不因拒絕同住而被懲罰或降低友情上限；未來依條件與意願仍可討論搬家或同住。

**共同原則**：兩種分支不等於選對／選錯；她有同意、拒絕和日後改變決定的權利，玩家同樣能保護自己的私人空間。研究機構住宿補助、住宅大小、空房與交通距離等未定案，不先硬寫死。

## 5. 〈ひかりの庭〉的敘事定位

使用者先前認為這首 AI 原創試作「很棒，但不像主題曲，比較像角色歌」；如今可以成為**這位地表新派遣者的印象曲候選**。歌詞中的陌生車站、燈光、土壤、水聲、逐漸建立歸屬感，可呼應她初抵歐姆的視角。

角色歌不等於她自己是歌手，也不代表一定要在月台播放完整歌曲。正式採用歌曲需要再核對創作品質及生成平台的商業條款；目前僅保存研究文字，不將音檔加入遊戲。
