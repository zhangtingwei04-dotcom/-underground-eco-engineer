# 《鱗片與種子：地下生態物語》｜歐姆日常音樂、歌唱與演奏文化 V0.1

> 建立日期：2026-11-08（Asia/Taipei）  
> 狀態：**世界觀方向已由使用者確認；下述具體活動、角色事件和實作細節仍屬候選提案，未視為正式功能或已完成程式。**  
> 階段：中後期再製作正式音樂；目前僅研究與文化規劃，不新增音訊素材、遊戲程式或支出。

## 1. 使用者確認的文化原則

1. 歐姆地下國的居民**每個人都有自己的生活**，有不同的工作、休息、朋友、家庭、個性、煩惱與喜好。
2. **大多數居民是熱情的人**；但「大多數」不等於全部，也不等於每個人都外向、整天開心、願意為玩家演出，或每一位都擅長音樂。
3. **唱歌與演奏很適合歐姆文化**。它可以作為國家居民日常生活、社交活動與文化表達的一部分，而不只是玩家耳中的背景音樂。
4. 正式配樂、角色歌曲與音樂系統應在**遊戲中後期才開始製作**；目前以多元音樂、自然聲景、遊戲原聲帶、動畫與二次元角色歌的**合法欣賞和研究**慢慢累積靈感，無須急著選曲或作曲。
5. 延續全遊戲慢生活原則：玩家可**旁觀、參與、不參加或錯過**，不因沒有聽音樂、參加演奏而受到登入懲罰或失去不可替代的主要進度。

## 2. 音樂是「居民自己會做的事」，不只是 BGM

建議將聲音區分為下列三層，避免概念混用：

- **故事世界內的音樂（diegetic music）**：NPC 確實在唱歌、吹奏、敲擊、練習、排練，或以世界內存在的裝置播放音樂；玩家會知道聲音來自何處，也可選擇停下來欣賞。
- **故事世界外的原創配樂（non-diegetic BGM）**：服務畫面氛圍、情緒或劇情的背景音樂，不一定有 NPC 正在演奏。
- **自然聲景**：地下水流、風、葉片、昆蟲、洞穴滴水、研究站機械及居民生活的環境聲；與上面兩種音樂的音量和場景需要合理混合。

以上為候選的未來聲音架構，不表示目前已製作完整的 3D 聲場或配樂播放器。

## 3. 居民的音樂性格與自主權（提案）

- 音樂偏好、是否會唱／會演奏、熟練程度、喜歡的風格、是否樂於公開表演，應是**角色各自的資料**；不能用單一「熱情＝必定愛唱歌」規則推導。
- 有些 NPC 擅長公開演奏；有些只在家裡練習；有人喜歡聽、不喜歡上台；有人完全沒音樂興趣。這些差別並非角色優劣，也不必全由好感度決定。
- NPC 可以因自己的日程、工作、心情、朋友或節慶，自發地去排練、欣賞、唱歌或取消演出。玩家不是世界活動的唯一觸發點。
- 自願演出或私人分享應尊重**關係、隱私與同意**：玩家不能透過刷好感強迫 NPC 表演、公開其私人錄音或取得秘密歌曲。
- 樂觀熱情的人也會有不開心的時候；較沉默的人也可能保留對音樂的強烈感情。維持角色的多面性。

## 4. 可能的歐姆生活畫面（以下均為候選，尚未定案）

| 場所／時刻 | 可能的聲音與活動 | 玩家是否必須參加 |
|---|---|---|
| 城鎮街道及廣場 | 朋友自發練習樂器、小型即興演奏、居民停下來聽 | 否 |
| 商店、咖啡館、便利商店 | 員工工作時輕哼熟悉曲調、店內播放居民喜歡的音樂 | 否 |
| 圖書館與文化活動區 | 小型音樂欣賞、在適當區域舉辦分享會、音樂歷史講座 | 否 |
| 家庭、朋友聚會 | 私下合唱、練習、送別歌曲或特殊紀念日的簡單旋律 | 否 |
| 地方節慶與季節變化 | 居民社群共同參與的歌曲、樂器及舞蹈；各地可能存在差異 | 否 |
| NPC 重要人生事件 | 特定旋律逐漸成為記憶的線索，不一定需要正式「角色歌」 | 否 |

這些例子只用來描述可能的生活感，不代表所有商店都一定有歌聲、每個節日都要辦演唱會，或每次進入場景都會固定重播相同曲目。

## 5. 歐姆文化的獨特性（未定案研究題）

- **自己的音樂習慣**：居民何時哼歌、是否有社區樂團、傳承方法與演奏禮節，可以在世界歷史和生活場景更完整後再設計。
- **不同世代／地區**：可有不同風格、常用樂器或節慶表現；不要把文化簡化成全國居民都唱同一首歌。
- **與地形與生態共存**：地下水、岩壁回響、濕潤洞穴、菌菇森林和城鎮材質，可能影響居民的聲音設計、演奏場所和音樂傳統；這仍是美術與聲學概念，不是現實科學已核實的歐姆地理事實。
- **原創為本**：可研究世界各地音樂、遊戲原聲帶、動畫角色歌曲如何建立文化感和人物辨識度，但不能直接搬用他人受保護的旋律、歌詞、角色或具辨識度的編曲。

## 6. NPC 角色歌與世界內演奏要分開

對重要 NPC 可以探索兩種彼此獨立的東西：

1. **角色主題曲／旋律動機**：用於劇情呈現角色、回憶、情緒或關係階段，未必在世界裡有人真正唱或演奏。
2. **角色自己的音樂生活**：該角色喜歡聽的曲目、會演奏的樂器、是否參加活動、是否願意分享私人歌曲。

不能因為「某個 NPC 有主題曲」就推導他本人是歌手；也不能因為背景音樂聽起來悲傷，就判斷 NPC 當下心情悲傷。日後仍須以已確立的角色個性、關係、記憶和日程決定。

## 7. 中後期開發、成本與效能原則

- **現階段**：只做合法音樂／聲景欣賞索引、不同文化表現的文字研究、NPC 自主生活的可能性整理。
- **中期**：若確定需要再設計少數可感知的世界內演奏事件、音訊分層及靜音／音量設定，優先低負擔、可中止／可離開、按事件觸發而非逐 NPC 全時間模擬。
- **後期**：根據實際遊戲成果再製作歐姆原創歌曲、NPC 的角色主題、音樂節慶、可回憶的表演記錄等，不預支成本，也不承諾每位居民都有自己的完整歌曲。
- **低成本／跨平台**：維持手機和電腦可玩、效能優先、正式配樂與遊戲外授權界線清楚，聲音無障礙與各類音量設定需要預留規劃。
- 不修改目前 `AudioSystem`、既有 BGM、玩家存檔或登入畫面；任何新增系統需另依測試與玩家體驗評估。
