# V26.0 NPC 情感、心情與記憶系統規格書

> 文件狀態：整合基礎／開發前規格草案  
> 數值門檻、個別 NPC 設定及事件機率仍待後續平衡  
> 適用專案：《鱗片與種子：地下生態物語》

## 一、系統核心理念

NPC 不只是提供任務、商店及對話的角色，而是具有獨立個性、情緒、生活及人際關係的個體。

NPC 會記住玩家的行為，對玩家產生不同情感，也會因自身生活發生的事情而改變心情。

本系統希望讓玩家感受到：
- NPC 有自己的生活，不會永遠等待玩家。
- NPC 會記得玩家曾經做過的事情。
- 不同 NPC 對相同事件可能有不同反應。
- 關係需要長期經營，也可能因行為而改變。
- 即使關係結束，重要回憶仍然存在。

## 二、三大情感數值

| 數值 | 主要用途 | 特性 |
|---|---|---|
| 好感度 | NPC 對玩家的親近程度 | 可以增加或下降 |
| 信任度 | NPC 是否相信玩家 | 重大事件可能留下長期影響 |
| 心情值 | NPC 當下的情緒狀態 | 隨生活及事件變化 |

三者獨立計算，不可直接互相取代。

例如：NPC 非常喜歡玩家，但今天因工作失敗而心情低落，仍可能拒絕聊天或不送禮。

## 三、好感度與關係階段

| 階段 | 初步數值 | 主要內容 |
|---|---:|---|
| 陌生 | 0–19 | 正式稱謂、保持距離 |
| 熟識 | 20–49 | 日常對話、逐漸熟悉 |
| 親近 | 50–79 | 使用玩家地下名字、個人故事 |
| 特殊羈絆 | 80–99 | 特殊事件、深層對話、告白機會 |
| 戀人 | 獨立判定 | 正式交往、專屬暱稱 |

以上數值為初步設定，未來依 NPC 個性調整。

戀人階段不會單純因為好感度達標而自動解鎖，必須完成正式告白事件。

## 四、好感度下降與個性影響

NPC 會根據玩家行為改變對玩家的看法。

可能造成好感度下降的行為：
- 長期沒有互動。
- 違背重要承諾。
- 欺騙 NPC。
- 做出 NPC 厭惡的事情。
- 傷害 NPC 重視的生物。
- 反覆忽略重要事件。

不同 NPC 有不同的厭惡事項與好感度衰減速度。

例如：
- 容易寂寞型：長期沒有互動容易失落。
- 獨立型：不容易因為長期沒見面而降低好感。
- 重視承諾型：特別在意失約。
- 自然守護型：討厭破壞植物與生態。
- 生命尊重型：反感傷害生物。

慢生活原則：關係變化應有合理節奏與清楚脈絡，不以短暫未登入作為普遍懲罰。長期疏遠的影響依 NPC 個性與既有關係決定。

## 五、稱呼與專屬暱稱系統

稱呼會隨著關係階段改變。

| 關係 | 稱呼方式 |
|---|---|
| 陌生 | 玩家地下姓氏＋「研究員」 |
| 熟識 | 正式稱呼或自然對話 |
| 親近 | 開始使用玩家地下名字 |
| 特殊羈絆 | 親密稱呼與特殊對話 |
| 戀人 | NPC 專屬暱稱 |

正式規則：
1. 玩家初次抵達地下王國時，於生物登記所辦理身分登記。
2. 登記所提供符合地下王國文化的姓名選項，由玩家選擇地下姓氏與名字；姓氏、名字分開儲存，並組成完整地下姓名。
3. NPC 初期使用「地下姓氏＋研究員」稱呼玩家。
4. 每位 NPC 有自己的本名使用門檻。
5. 專屬暱稱由 NPC 依其個性與關係自行決定。
6. 不同 NPC 可擁有不同暱稱。
7. 關係降級時，稱呼也會跟著改變。
8. 分手後不再自然使用戀人專屬暱稱。
9. 地下王國日常互動只使用玩家地下姓名；玩家地上現實姓名受到保密規則保護，除地上研究所來信或明確設定的特殊情況外，不提供 NPC 日常稱呼使用。
10. 玩家地下姓名的修改流程及是否允許更名，仍待決定。

## 六、心情值與情緒狀態

每位 NPC 擁有獨立的心情值，初步採用 0–100。

| 心情值 | 情緒狀態 |
|---:|---|
| 0–19 | 非常低落 |
| 20–39 | 不開心 |
| 40–59 | 普通 |
| 60–79 | 愉快 |
| 80–100 | 非常開心 |

心情不會每天午夜自動重設。

心情可能受到以下因素影響：
1. 玩家互動。
2. NPC 自身生活。
3. 工作及研究成果。
4. 其他 NPC 的關係。
5. 城邦事件與節慶。
6. 季節及環境變化。
7. NPC 個人性格。

## 七、心情對 NPC 行為的影響

| 情緒狀態 | 可能出現的行為 |
|---|---|
| 非常低落 | 拒絕部分互動、獨處、簡短對話 |
| 不開心 | 不主動聊天、不送禮、減少邀約 |
| 普通 | 正常日常互動 |
| 愉快 | 主動聊天、分享生活 |
| 非常開心 | 特殊對話、主動邀約、驚喜禮物 |

注意：
- NPC 心情不好而不送禮，不代表 NPC 不喜歡玩家。
- 送禮需要考慮 NPC 心情、好感度、關係階段、經濟狀況、個性及禮物準備狀態。
- 玩家無法單純透過花錢控制 NPC 情緒。

## 八、NPC 情緒事件

心情變化可以觸發個人事件。

| 事件 | 內容 |
|---|---|
| 獨自待著 | NPC 心情低落，選擇獨處 |
| 情緒來信 | NPC 主動寫信透露近況 |
| 安靜陪伴 | 玩家可以不說話，只陪在身邊 |
| 心情好轉 | NPC 逐漸恢復正常互動 |
| 特殊感謝 | NPC 因玩家的陪伴留下深刻印象 |

玩家不一定要解決 NPC 的問題。有時候給予空間，比強迫對方交談更適合。

## 九、告白與關係破裂

告白需要考慮：
- 好感度。
- 信任度。
- 個人故事進度。
- NPC 個性。
- 當前情緒與劇情狀態。

告白失敗後：
1. 好感度大幅下降。
2. 暫時限制親密互動。
3. 對話變得尷尬或拘謹。
4. 進入個別 NPC 的疏遠期。
5. 需要重新建立信任。
6. 再次告白的可能性依 NPC 個性及劇情決定。

戀人也可能因重大衝突而分手。即使分手，NPC 仍會保留過去的共同回憶。

## 十、NPC 記憶庫

NPC 會記錄重要的人際事件。

| 記憶類型 | 記錄內容 |
|---|---|
| 初次相遇 | 第一次見面日期 |
| 初次互動 | 第一次主動聊天 |
| 名字記憶 | 第一次叫出彼此名字 |
| 歌曲記憶 | 第一次聽見專屬歌曲 |
| 承諾記憶 | 答應、完成或違背約定 |
| 共同回憶 | 一起參與的活動 |
| 戀愛記憶 | 告白、交往、分手日期 |
| 暱稱記憶 | 第一次使用專屬暱稱 |
| 情緒記憶 | 第一次在低落時受到陪伴 |

這些紀錄可用於觸發特殊對話、紀念日及個人劇情。關係結束或階段下降，不得任意刪除重要共同回憶。

## 十一、專屬歌曲系統

每位 NPC 可以擁有自己的專屬歌曲。

可能解鎖條件：
- 完成個人故事。
- 第一次聽見 NPC 演奏。
- 達成特殊羈絆。
- 成為戀人。
- 完成特殊紀念事件。

歌曲會與 NPC 記憶系統連動，成為兩人共同回憶的一部分。歌曲素材需使用原創或已取得合法授權的內容。

## 十二、NPC 個人生活週期

NPC 不會永遠等待玩家。

可能擁有：
- 固定工作時間。
- 個人休息日。
- 研究進度。
- 個人節日。
- 特定日期的情緒變化。
- 與其他 NPC 的社交活動。
- 個人壓力與恢復週期。

採用事件及日程模擬，不要求所有 NPC 都進行複雜的逐日情緒運算。玩家離線期間的重要事件應保留，回來後可透過對話、信件或記憶紀錄了解，不應因未登入而錯過所有內容。

所有系統需支援繁體中文與英文，不將玩家可見文字直接寫死在程式邏輯中；其他已規劃語言也應可透過語言資料擴充。

## 十四、正式設計原則

1. 每位 NPC 都有獨立個性。
2. 好感度、信任度與心情值分開運作。
3. NPC 會記住玩家的重要行為。
4. NPC 有自己的生活，不會永遠等待玩家。
5. 心情不好時可能拒絕互動或不送禮。
6. 玩家無法單純透過花錢控制 NPC 情緒。
7. 專屬暱稱只屬於特定 NPC 與玩家。
8. 關係破裂不會刪除過去的共同回憶。
9. 情緒事件應有不同結果，而非單純增加或扣除數值。
10. 每段關係都應具有自己的故事。
11. NPC 稱呼玩家時必須遵守地下姓名與地上現實姓名的保密規則。

## 十五、與其他系統的連動

- **雙名字與生物登記所**：玩家地下姓名由登記所提供選項並由玩家選定；姓氏與名字分開儲存。地上現實姓名依身分保密政策管理。
- **私人領地許可**：NPC 的好感度、信任度、心情、個性與記憶可共同影響私人領地邀請、獨自探索許可、暫停及重新授權。
- **每週研究報告**：NPC 可依研究成果、合作經歷與個性給予不同回應，但不得虛構玩家未完成的研究。
- **生物照護與保育**：NPC 對生命、棲地及玩家照護行為的價值觀會影響好感、信任及事件結果。

## 十六、女性生命守護巡查員、面具指導員與專屬回憶相冊（V26.0 補充）

> 本節整理已確認的角色方向與系統規則。角色姓名、精確數值門檻、事件條件及個別劇情台詞仍待後續設計。

### 16.1 女性生命守護巡查員的角色核心

- 地下王國存在生命守護組織，會定期派遣固定的女性 NPC 前往玩家研究站巡查與拜訪。
- 她初期以熱情、友善、健談、親切的鄰家感與玩家互動；玩家起初不一定知道她真正的組織身分與巡查職責。
- 她的熱情有一部分是面對外界的面具與自我保護方式，但她的善良、熱情與對生命的關心也是真實的，不可簡化成「外表開朗、內心悲傷」的單一反差角色。
- 她從小可能承受家庭或重要人物的期待，習慣把他人的需求與責任放在自己之前；完整過去由劇情逐步塑造，不以單一創傷定義她。
- 她對生命守護工作既有真正的熱愛、成就感與責任，也可能有疲憊、質疑及制度上的兩難。她可能因家庭／組織期待走入此領域，之後逐漸找到自己的理想。
- 她真心認同保護生命，但不代表完全認同組織的每項制度。她會建立自己的價值判斷，不會盲目服從，也不會為了玩家而永遠偏袒玩家。
- 她有自己的朋友、家庭關係、工作成就與挫折、私人生活、夢想及錯誤決定；即使玩家沒有出現，她的生活仍會繼續。
- 她的情感、心情、記憶與關係變化，整合既有 NPC 情感、心情與記憶系統。

### 16.2 巡查判斷與拜訪變化

- 她依事件嚴重程度、涉及生命的風險、玩家行為是否故意、她掌握的事實、玩家補救態度及雙方信任程度作出判斷。
- 輕微事件可能以提醒與私下協助處理；一般事件可能造成信任下降、調查或暫停部分互動；嚴重事件可能使她停止例行拜訪。
- 玩家造成嚴重違規或重大生命安全問題時，她可能不再出現在玩家研究站。她的離開必須有世界觀及劇情理由，不只是單純的好感度懲罰。
- 她停止拜訪後，可透過其他 NPC 的近況、組織通知、任務變化等方式讓玩家理解後續；不得把所有內容都變成冗長文件流程。
- 是否能重新建立關係依事件性質決定：部分事件可透過長期補救與信任重建挽回；部分重大且不可逆的事件可能永遠無法挽回。
- 組織恢復玩家資格，不代表她個人必須原諒玩家；組織處分與 NPC 私人情感分開判定。

### 16.3 教育優先的生命守護違規處理

核心原則：遊戲讓玩家理解責任，但不要求玩家承受與現實相同的繁瑣程序與壓力。玩家犯錯後應有機會理解、改善與學習，而不是因害怕犯錯而不敢嘗試。

- 採教育、改善與復育優先，不設計繁瑣司法、聽證或冗長申訴流程。
- 輕微疏失以 NPC 引導、知識說明、實際改善、研究紀錄及反思為主。
- 依事件嚴重程度才施加功能限制；不可因一次無心疏失就永久封鎖遊戲內容。
- 嚴重違規可暫時吊銷相關研究／保育執照數個遊戲日。遊戲世界時間持續流動，停權天數不因玩家離線而暫停。
- 停權只限制該執照對應的活動，例如特殊物種取得、相關繁殖或部分保育區活動；不得封鎖基本遊玩、既有動物照護、一般研究站生活與一般探索。
- 停權期限與限制範圍需清楚告知。可透過學習、改善、照護或復育行動完成教育要求；不要求複雜申訴程序。
- 已持有的動物仍須受到正常照護，不可因玩家停權而被系統任意沒收或停止照顧。
- 對於不可逆的重大生命傷害，執照到期不會自動抹除事件後果、受害生命的損失或 NPC 的個人記憶。
- 違規學習可使用多種方式：NPC 指導、百科與科普、動物行為觀察、照護實作、環境改善、研究紀錄及生態探索。責任心與學習不應只靠扣分或懲罰。

### 16.4 面具指導員特別劇情

- 玩家受到相關執照停權時，可由一位特別指導員／老師到研究站協助學習生命照護、保育規範與改善方法。
- 這位指導員可能就是女性生命守護巡查員本人，但她戴著特殊面具，以不同身分或不公開原本身分的方式出現。
- 面具指導員以實際教學、環境檢查、物種習性說明、照護改善與個人經驗分享為主，不以冗長講課或額外行政程序增加玩家負擔。
- 玩家可能從語氣、習慣、專業知識、特殊用語或情緒反應逐漸察覺她的身分。
- 身分揭露方式依玩家與她的好感、信任、實際互動及劇情旗標決定；玩家可能提前察覺，也可能在關係進展後才理解真相。
- 她可能在停權期間真正協助玩家，但她是否願意這麼做、如何表現，仍取決於事件嚴重程度與她自己的原則。

### 16.5 特殊回憶解鎖與記憶伏筆

- 玩家與該 NPC 的關係達到適當進度後，可逐步解鎖與面具指導員事件相關的回憶紀錄。
- 回憶可能讓玩家產生「我怎麼會有這段回憶？」的疑惑，並從先前實際經歷的細節中逐漸連結面具指導員與女性巡查員。
- 回憶解鎖不應只依單一好感度數值；應結合好感、信任、事件經歷及劇情旗標。
- 回憶只可記錄玩家實際經歷過的事件；不可憑空植入未發生的互動。
- 回憶系統主要呈現方式選擇「相簿＋日記」，不以可重播完整場景作為必要形式。相簿保存事件畫面與照片，日記呈現 NPC 當時的感受、想法或事後反思。
- 一般 NPC 記憶庫仍然對所有 NPC 開放；戀人資格不是 NPC 記得玩家的前提。

### 16.6 戀人專屬共用相冊

- 玩家與 NPC 正式進入戀人關係後，才開放兩人專屬的共用相冊。這是親密關係的專屬分享空間，不取代一般 NPC 記憶庫。
- 共用相冊同時支援玩家主動拍照與系統自動收錄實際發生的重要紀念照片。
- 玩家可拍攝 NPC、動物、研究所、日常生活、約會、旅行及節日場景，並自行挑選照片加入共用相冊。
- 系統可在第一次約會、重要紀念日、共同旅行、節日、特殊劇情及其他有意義的實際事件後，自動保存紀念照片。
- 照片可附上日期、地點及簡短回憶文字；照片中的角色外觀、動物個體、場景與事件必須符合當時遊戲資料，不可捏造未發生的共同經歷。
- NPC 會依個性、關係、情境與當下心情決定是否主動替玩家拍照。攝影愛好者可能主動邀請或拍攝；害羞者可能只在特定情境留下照片；念舊者可能私下收藏玩家照片；其他 NPC 也可有不同表現。
- NPC 是否把照片分享給玩家、加入共用相冊或私下收藏，依其個性、關係進度及事件情境決定。
- NPC 主動拍攝的照片也必須來自遊戲中實際發生的場景，不可捏造經歷。

### 16.7 分手後的共用相冊處理

- 分手不會自動刪除曾經發生的共同經歷與照片。
- 相冊後續依 NPC 個性、分手原因、當前心情、信任與關係狀態決定，可能保留並偶爾翻閱、封存、轉為各自私人回憶，或停止共同編輯。
- 不同 NPC 可以有不同反應；不得一律套用相同處理方式。
- 關係結束後，共用相冊不再作為持續共同編輯的戀人功能，但既有回憶仍應保留其歷史紀錄。

### 16.8 慢生活與玩家體驗保護

- 不以短暫未登入、一次無心錯誤或未完成所有日常照護操作，作為普遍而嚴重的懲罰理由。
- 重要事件與回憶需可在玩家回來後理解，不用要求玩家每日登入才能維持 NPC 關係或避免錯過核心內容。
- 懲罰應讓玩家理解行為後果並有合理補救方式；不能把遊戲變成現實行政流程的複製品。
- NPC 有自己的原則與生活，但玩家仍應保有繼續遊玩、照顧既有動物及探索世界的基本能力。



## 十七、NPC 離線生活與低負擔事件模擬

**狀態：設計方向已確認；模擬週期、事件優先級與資料結構待技術設計。**

### 17.1 核心原則

NPC 的生活在玩家離線時仍可持續發展，但系統不需要持續運行所有 NPC 的完整 AI。採用「重要事件優先、依個體差異決定模擬深度」的方式，在世界持續感與系統負擔之間取得平衡。

### 17.2 降低運算負擔

- 不要求所有 NPC 在離線期間逐分鐘運算。
- 不模擬每一次日常對話、每個細微動作或所有 NPC 間的完整社交過程。
- 不建立不必要的高頻更新或大量事件紀錄。
- 優先採低頻結算、事件摘要與必要狀態更新；實際排程與技術架構於實作前評估。

### 17.3 重要事件優先

離線期間優先處理可能影響 NPC 長期狀態或玩家後續體驗的事件，例如重要工作／研究進度、關係重大互動或衝突、特殊人生事件、明顯且有原因的心情變化，以及重要照片與記憶事件。一般瑣碎活動可以摘要處理，不必逐項保存。

### 17.4 依 NPC 個體差異決定

- 模擬與紀錄內容依 NPC 個性、生活安排、工作、關係、心情與當時事件決定。
- 社交型 NPC 可能留下較多重要社交事件；偏好獨處或工作型 NPC 的離線紀錄則可能不同。
- 差異必須有角色設定與事件原因，不以無根據的隨機事件填充。
- 同一 NPC 在不同生活階段也可能有不同活動重心。

### 17.5 玩家回歸後的資訊呈現

玩家回到遊戲後，可透過自然對話、日記、信件、照片或 NPC 記憶紀錄得知重要近況。無關緊要的細節不必全部列出，也不應讓玩家被大量離線報告淹沒。

### 17.6 與慢生活原則整合

- NPC 世界持續運作，不代表玩家必須每日登入追進度。
- 不應因玩家離線而錯過所有重要內容；重要事件需保留合理的回顧或後續互動方式。
- 離線模擬應兼顧世界可信度、玩家心理負擔、效能與開發可行性。
- 此設計是事件導向的生活模擬，不是全世界每個角色的即時 AI 模擬。

## 十八、NPC 心理特質、抗壓性與個人成長

**狀態：核心方向已確認；個別 NPC 初始參數、數值模型與具體事件權重待後續技術設計。**

### 18.1 核心理念

NPC 的心理狀態不應只由單一心情值或好感度決定。每位 NPC 都有自己的心理特質、面對壓力的方式、情緒恢復節奏與人生經歷。相同事件可以在不同 NPC 身上造成不同影響；同一位 NPC 也會因人生經歷而逐漸改變。

### 18.2 心理特質採多維度設計

以下特質彼此獨立，不可把它們合併成單一「開朗／脆弱」標籤：

| 心理維度 | 設計意義 |
|---|---|
| 樂觀／悲觀傾向 | NPC 習慣如何解讀事情、預期未來與看待可能結果 |
| 抗壓性 | 面對壓力、挫折與衝突時，承受及維持基本生活功能的能力 |
| 情緒恢復力 | 受到情緒衝擊後，逐步回到自身平衡狀態的速度與方式 |
| 情緒敏感度 | 對環境、人際互動、批評、失落與變化的感受程度 |
| 自我調適能力 | NPC 辨識、理解及整理自身情緒的能力 |

各維度可以自由組合。例如樂觀者不一定抗壓性高；悲觀者也可能非常堅韌。高抗壓性不代表不會受傷或不需要支持，低抗壓性也不代表角色軟弱或缺乏價值。

### 18.3 先天性格基礎與後天經歷

- 每位 NPC 登場時具有符合其背景的初始心理特質，作為其性格基礎。
- 心理特質並非永遠固定。家庭、友情、愛情、工作、成功、失敗、重大挫折、長期壓力、支持與自我反思，都可能逐漸塑造或改變 NPC。
- 人格或心理傾向的改變應有累積經歷、重大事件或長期脈絡支持，不因單一普通事件突然大幅轉變。
- 成長不必只有正向結果：NPC 可能變得更成熟、更有自信，也可能變得敏感、退縮、悲觀或更重視界線。
- 改變後仍保留過去的經歷與記憶，不應覆寫成彷彿從未發生過。
- 心理特質變化應是角色人生的一部分，不是玩家可透過單一選項或送禮直接控制的數值。

### 18.4 心理韌性對生活層面的影響

事件對 NPC 的影響由事件嚴重程度、個人心理特質、過往記憶、當前壓力與可用支持共同決定。可能影響：

- 情緒狀態與恢復時間。
- 工作、研究、休息與日常生活安排。
- 社交意願、聚會參與及主動聯繫。
- 對朋友、家人、戀人及玩家的互動方式。
- 是否傾訴、求助、拒絕幫助或暫時保持距離。
- 對承諾、衝突與未來事件的看法。

不要求每個層面都同時受到影響，也不要求所有 NPC 出現相同症狀或反應。某些 NPC 可能維持工作但減少社交；某些 NPC 可能表面如常、私下承受壓力；也有人會主動尋求陪伴。外在表現不必然等於內心狀態。

### 18.5 個人心理調適方式

每位 NPC 依個性、生活習慣、過往經歷及人際關係，逐漸形成自己的調適方式。可能包括獨處、與朋友交談、尋求陪伴、投入工作或研究、從事興趣、運動、散步、旅行、整理環境或其他個人習慣。

- 調適方式不應只限於一組所有 NPC 共用的固定選項。
- 同一 NPC 可能同時具有多種方式，並依情境選擇。
- 有些調適方式可能有效，有些可能只是短暫轉移注意力，也可能存在逃避、壓抑、過度投入工作或衝動行為等不理想方式。
- 不健康的調適方式不等於角色道德不好；應以角色脈絡呈現其形成原因及可能後果，不以標籤羞辱角色。
- NPC 可以在生活經驗、反思及可信任的人際支持中逐漸學習新的調適方式，但不保證每次都成功，也不保證一定接受玩家的協助。
- 支持者可以是朋友、家人、戀人、同事或玩家；NPC 仍保有拒絕、延後或選擇其他支持來源的權利。

### 18.6 心情恢復與離線結算

- NPC 的心情可能因重要事件而改變，也可能隨時間、生活安排、個人調適方式及支持情況逐步恢復。
- 恢復速度與過程依個體的抗壓性、情緒恢復力、敏感度、調適能力、事件嚴重程度及過往經歷決定。
- 重要事件造成的記憶與可能的長期影響不會因心情值恢復就自動消失。
- 不使用所有 NPC 共用的固定恢復曲線，也不把抗壓性簡化成心情恢復速度單一參數。
- 離線期間沿用既有低負擔原則：以重要事件、低頻結算與必要狀態更新為主，不執行每分鐘完整心理模擬，也不保存每次細微情緒波動。
- 玩家回歸後可透過自然互動、日記、信件、照片或記憶紀錄得知有意義的變化，不必收到冗長的離線心理報告。

### 18.7 NPC 自主表達、隱私與求助

NPC 是否向玩家透露心理狀態、透露多少，以及何時透露，皆由角色自主決定。判斷可考慮個性、當下心情、信任、關係階段、過往互動、事件性質、環境及談話情境。

- 有些 NPC 會主動傾訴；有些只透露「最近比較累」等有限訊息；有些需要長期相處才會讓玩家察覺；也有人即使是戀人仍會保留私人空間。
- NPC 可以主動尋求幫助，也可以拒絕幫助、暫時不談或選擇向其他人求助。
- 玩家不能只靠達到好感度門檻就自動取得 NPC 的所有內心資訊。
- NPC 的言語、行為與生活變化可以提供線索，但不應保證玩家每次都能立即正確理解。
- NPC 的自主表達必須符合角色一貫特質與當下情境，不以毫無根據的隨機隱瞞或突然告白製造戲劇效果。

### 18.8 設計與效能原則

本系統是角色導向、事件驅動的心理生活模擬，不是完整心理學診斷，也不是每位 NPC 的即時 AI。實作時應以少量可解釋的心理維度、重要事件紀錄、低頻狀態結算及角色個別設定，呈現足夠豐富的差異。避免堆疊大量互相重複的數值、逐分鐘更新或無法被玩家感知的昂貴運算。

### 18.9 正式設計原則摘要

1. 樂觀／悲觀傾向與抗壓性分開設計，不能互相推定。
2. 抗壓性、情緒恢復力、敏感度與自我調適能力是不同維度。
3. NPC 具有先天心理基礎，也會被後天人生經歷逐漸塑造。
4. 心理韌性會依事件與個體差異影響生活、工作、社交及人際互動，不只影響心情數值。
5. 每位 NPC 會形成自己的調適方式，可能健康，也可能不理想。
6. 心情可以逐漸恢復，但重要事件記憶及長期影響不會因此自動消失。
7. NPC 自主決定是否向玩家透露心事、尋求幫助或保留隱私。
8. 離線心理模擬遵循重要事件優先、低頻結算與低負擔原則。
