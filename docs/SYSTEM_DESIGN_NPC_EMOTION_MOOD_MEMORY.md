# V26.0 NPC 情感、心情與記憶系統規格書

> 文件狀態：整合基礎／開發前規格草案  
> 數值門檻、個別 NPC 設定及事件機率仍待後續平衡  
> 適用專案：《鱗片與種子：地下生態物語》

## 一、系統核心理念

NPC 不只是提供任務、商店及對話的角色，而是具有獨立個性、情緒、生活及人際關係的個體。

NPC 會記住玩家的行為，對玩家產生不同情感，也會因自身生活發生的事情而改變心情。

本系統希望讓玩家感受到：
- NPC 有自己的生活，不會永遠等待玩家。
- NPC 會記得玩家曾經做過的事情。
- 不同 NPC 對相同事件可能有不同反應。
- 關係需要長期經營，也可能因行為而改變。
- 即使關係結束，重要回憶仍然存在。

## 二、三大情感數值

| 數值 | 主要用途 | 特性 |
|---|---|---|
| 好感度 | NPC 對玩家的親近程度 | 可以增加或下降 |
| 信任度 | NPC 是否相信玩家 | 重大事件可能留下長期影響 |
| 心情值 | NPC 當下的情緒狀態 | 隨生活及事件變化 |

三者獨立計算，不可直接互相取代。

例如：NPC 非常喜歡玩家，但今天因工作失敗而心情低落，仍可能拒絕聊天或不送禮。

## 三、好感度與關係階段

| 階段 | 初步數值 | 主要內容 |
|---|---:|---|
| 陌生 | 0–19 | 正式稱謂、保持距離 |
| 熟識 | 20–49 | 日常對話、逐漸熟悉 |
| 親近 | 50–79 | 使用玩家地下名字、個人故事 |
| 特殊羈絆 | 80–99 | 特殊事件、深層對話、告白機會 |
| 戀人 | 獨立判定 | 正式交往、專屬暱稱 |

以上數值為初步設定，未來依 NPC 個性調整。

戀人階段不會單純因為好感度達標而自動解鎖，必須完成正式告白事件。

## 四、好感度下降與個性影響

NPC 會根據玩家行為改變對玩家的看法。

可能造成好感度下降的行為：
- 長期沒有互動。
- 違背重要承諾。
- 欺騙 NPC。
- 做出 NPC 厭惡的事情。
- 傷害 NPC 重視的生物。
- 反覆忽略重要事件。

不同 NPC 有不同的厭惡事項與好感度衰減速度。

例如：
- 容易寂寞型：長期沒有互動容易失落。
- 獨立型：不容易因為長期沒見面而降低好感。
- 重視承諾型：特別在意失約。
- 自然守護型：討厭破壞植物與生態。
- 生命尊重型：反感傷害生物。

慢生活原則：關係變化應有合理節奏與清楚脈絡，不以短暫未登入作為普遍懲罰。長期疏遠的影響依 NPC 個性與既有關係決定。

## 五、稱呼與專屬暱稱系統

稱呼會隨著關係階段改變。

| 關係 | 稱呼方式 |
|---|---|
| 陌生 | 玩家地下姓氏＋「研究員」 |
| 熟識 | 正式稱呼或自然對話 |
| 親近 | 開始使用玩家地下名字 |
| 特殊羈絆 | 親密稱呼與特殊對話 |
| 戀人 | NPC 專屬暱稱 |

正式規則：
1. 玩家初次抵達地下王國時，於生物登記所辦理身分登記。
2. 登記所提供符合地下王國文化的姓名選項，由玩家選擇地下姓氏與名字；姓氏、名字分開儲存，並組成完整地下姓名。
3. NPC 初期使用「地下姓氏＋研究員」稱呼玩家。
4. 每位 NPC 有自己的本名使用門檻。
5. 專屬暱稱由 NPC 依其個性與關係自行決定。
6. 不同 NPC 可擁有不同暱稱。
7. 關係降級時，稱呼也會跟著改變。
8. 分手後不再自然使用戀人專屬暱稱。
9. 地下王國日常互動只使用玩家地下姓名；玩家地上現實姓名受到保密規則保護，除地上研究所來信或明確設定的特殊情況外，不提供 NPC 日常稱呼使用。
10. 玩家地下姓名的修改流程及是否允許更名，仍待決定。

## 六、心情值與情緒狀態

每位 NPC 擁有獨立的心情值，初步採用 0–100。

| 心情值 | 情緒狀態 |
|---:|---|
| 0–19 | 非常低落 |
| 20–39 | 不開心 |
| 40–59 | 普通 |
| 60–79 | 愉快 |
| 80–100 | 非常開心 |

心情不會每天午夜自動重設。

心情可能受到以下因素影響：
1. 玩家互動。
2. NPC 自身生活。
3. 工作及研究成果。
4. 其他 NPC 的關係。
5. 城邦事件與節慶。
6. 季節及環境變化。
7. NPC 個人性格。

## 七、心情對 NPC 行為的影響

| 情緒狀態 | 可能出現的行為 |
|---|---|
| 非常低落 | 拒絕部分互動、獨處、簡短對話 |
| 不開心 | 不主動聊天、不送禮、減少邀約 |
| 普通 | 正常日常互動 |
| 愉快 | 主動聊天、分享生活 |
| 非常開心 | 特殊對話、主動邀約、驚喜禮物 |

注意：
- NPC 心情不好而不送禮，不代表 NPC 不喜歡玩家。
- 送禮需要考慮 NPC 心情、好感度、關係階段、經濟狀況、個性及禮物準備狀態。
- 玩家無法單純透過花錢控制 NPC 情緒。

## 八、NPC 情緒事件

心情變化可以觸發個人事件。

| 事件 | 內容 |
|---|---|
| 獨自待著 | NPC 心情低落，選擇獨處 |
| 情緒來信 | NPC 主動寫信透露近況 |
| 安靜陪伴 | 玩家可以不說話，只陪在身邊 |
| 心情好轉 | NPC 逐漸恢復正常互動 |
| 特殊感謝 | NPC 因玩家的陪伴留下深刻印象 |

玩家不一定要解決 NPC 的問題。有時候給予空間，比強迫對方交談更適合。

## 九、告白與關係破裂

告白需要考慮：
- 好感度。
- 信任度。
- 個人故事進度。
- NPC 個性。
- 當前情緒與劇情狀態。

告白失敗後：
1. 好感度大幅下降。
2. 暫時限制親密互動。
3. 對話變得尷尬或拘謹。
4. 進入個別 NPC 的疏遠期。
5. 需要重新建立信任。
6. 再次告白的可能性依 NPC 個性及劇情決定。

戀人也可能因重大衝突而分手。即使分手，NPC 仍會保留過去的共同回憶。

## 十、NPC 記憶庫

NPC 會記錄重要的人際事件。

| 記憶類型 | 記錄內容 |
|---|---|
| 初次相遇 | 第一次見面日期 |
| 初次互動 | 第一次主動聊天 |
| 名字記憶 | 第一次叫出彼此名字 |
| 歌曲記憶 | 第一次聽見專屬歌曲 |
| 承諾記憶 | 答應、完成或違背約定 |
| 共同回憶 | 一起參與的活動 |
| 戀愛記憶 | 告白、交往、分手日期 |
| 暱稱記憶 | 第一次使用專屬暱稱 |
| 情緒記憶 | 第一次在低落時受到陪伴 |

這些紀錄可用於觸發特殊對話、紀念日及個人劇情。關係結束或階段下降，不得任意刪除重要共同回憶。

## 十一、專屬歌曲系統

每位 NPC 可以擁有自己的專屬歌曲。

可能解鎖條件：
- 完成個人故事。
- 第一次聽見 NPC 演奏。
- 達成特殊羈絆。
- 成為戀人。
- 完成特殊紀念事件。

歌曲會與 NPC 記憶系統連動，成為兩人共同回憶的一部分。歌曲素材需使用原創或已取得合法授權的內容。

## 十二、NPC 個人生活週期

NPC 不會永遠等待玩家。

可能擁有：
- 固定工作時間。
- 個人休息日。
- 研究進度。
- 個人節日。
- 特定日期的情緒變化。
- 與其他 NPC 的社交活動。
- 個人壓力與恢復週期。

採用事件及日程模擬，不要求所有 NPC 都進行複雜的逐日情緒運算。玩家離線期間的重要事件應保留，回來後可透過對話、信件或記憶紀錄了解，不應因未登入而錯過所有內容。

## 十三、預計程式模組

| 模組 | 職責 |
|---|---|
| npc-relationship-system.js | 好感度、關係階段 |
| npc-personality-system.js | 個性、喜惡、偏好 |
| npc-mood-system.js | 心情值、情緒變化 |
| npc-memory-vault.js | NPC 長期記憶 |
| npc-naming-system.js | 正式稱呼、本名、暱稱 |
| npc-romance-system.js | 告白、交往、分手 |
| npc-event-system.js | 個人及情緒事件 |
| npc-gift-system.js | 送禮判定及紀錄 |
| npc-dialogue-system.js | 動態對話 |
| npc-music-system.js | 專屬歌曲及解鎖紀錄 |

所有系統需支援繁體中文與英文，不將玩家可見文字直接寫死在程式邏輯中；其他已規劃語言也應可透過語言資料擴充。

## 十四、正式設計原則

1. 每位 NPC 都有獨立個性。
2. 好感度、信任度與心情值分開運作。
3. NPC 會記住玩家的重要行為。
4. NPC 有自己的生活，不會永遠等待玩家。
5. 心情不好時可能拒絕互動或不送禮。
6. 玩家無法單純透過花錢控制 NPC 情緒。
7. 專屬暱稱只屬於特定 NPC 與玩家。
8. 關係破裂不會刪除過去的共同回憶。
9. 情緒事件應有不同結果，而非單純增加或扣除數值。
10. 每段關係都應具有自己的故事。
11. NPC 稱呼玩家時必須遵守地下姓名與地上現實姓名的保密規則。

## 十五、與其他系統的連動

- **雙名字與生物登記所**：玩家地下姓名由登記所提供選項並由玩家選定；姓氏與名字分開儲存。地上現實姓名依身分保密政策管理。
- **私人領地許可**：NPC 的好感度、信任度、心情、個性與記憶可共同影響私人領地邀請、獨自探索許可、暫停及重新授權。
- **每週研究報告**：NPC 可依研究成果、合作經歷與個性給予不同回應，但不得虛構玩家未完成的研究。
- **生物照護與保育**：NPC 對生命、棲地及玩家照護行為的價值觀會影響好感、信任及事件結果。
