# 《地下生態工程師》V1.0 開發總計畫 (Underground Eco-Engineer)

## 📌 遊戲定位與核心理念
* **遊戲定位**：地下生態探索, 經營, 模擬與建設遊戲[cite: 1]。
* **核心理念**：玩家扮演地下生態工程師, 透過挖掘地下空間, 收集資源, 培育生物, 調節環境及建設棲息地, 逐步建立一個能夠自行運作, 持續成長的地下生態系統[cite: 1]。
* **預設語系**：繁體中文（zh-TW）與英文（en）[cite: 1]。
* **開發架構**：網頁優先（Phaser 3 + JavaScript/TypeScript + JSON 資料驅動）[cite: 1]。

---

## ⚙️ 一, 核心遊戲循環 (Core Loop)
1. **選擇生物**：從已解鎖圖鑑選擇生物配置到地下探索區域[cite: 1]。
2. **挑戰地下方塊**：根據挖掘能力選擇能挖掘的沙土（5）, 泥土（15）或岩石（50）[cite: 1]。
3. **消耗精力**：挖掘消耗精力, 需考慮體力, 休息及生物能力[cite: 1]。
4. **拓展地下空間**：挖掘成功後開拓新區域, 發現資源及特殊地形[cite: 1]。
5. **經營地下生態**：改善環境, 種植植物, 培育生物, 建立完整生態[cite: 1]。

---

## 🛠️ 二, 主要系統規劃
1. **地下挖掘系統**：包含方塊硬度, 耐久度（HP）, 多層地層剖面生成與精力消耗[cite: 1, 2]。
2. **生物管理系統**：個體屬性（挖掘力, 精力, 壓力, 溫濕度偏好）, 固定身分 + 隨機外觀[cite: 1, 2]。
3. **生物圖鑑與解鎖系統**：包含未解鎖剪影, 生物習性與解鎖進度[cite: 1]。
4. **地下環境模擬系統**：深度與動態溫濕度變化, 環境失衡警告[cite: 1, 2]。
5. **植物與微生態系統**：苔蘚, 真菌, 土壤微生物與生態循環（未來擴充）[cite: 1]。
6. **棲息地建設系統**：休息區, 水源區, 種植區, 溫濕度調節設備（未來擴充）[cite: 1]。
