《鱗片與種子：地下生態物語》V1.0 開發總計畫 (Scales & Seeds: Underground Ecosystem Story)

「照顧一個生命，不代表永遠把牠留在身邊。有時候，理解牠真正需要的生活，才是最好的陪伴。」

📌 1. 遊戲定位與核心理念

1.1 遊戲定位

遊戲名稱：《鱗片與種子：地下生態物語》（Scales & Seeds: Underground Ecosystem Story）

類型：生活派地下生態探索、觀察日誌、模組化棲息地建造與多物種生態照護。

開發架構：網頁優先（Phaser 3 + ES Module JavaScript/TypeScript + JSON 資料驅動）。

預設語系：繁體中文（zh-TW）與英文（en）。

1.2 核心哲學：Gentle, but not guaranteed forever（溫柔，但不保證永遠）

真實生命的重量：生命有限且珍貴。生態系統不因玩家離線而停止運作， death 是自然的歷程而非遊戲化的懲罰。

非傳統寵物養成：

❌ 無付費復活：不販售逆轉生命的道具。

❌ 無難度切換：維持統一的生命與生理運作規則。

❌ 無隨意買賣：生命絕非可充當商品隨意轉售賺錢的流動資產。

觀察高於控制：著重於觀察不同物種在對應環境中的日常習性與微小細節，而非強制馴服。

⚙️ 2. 三大核心架構原則

[ 物種 (Species) ]  ───►  決定生理需求與行為傾向 (如：攀爬 vs 挖掘)
[ 個體 (Individual) ] ───►  決定性格偏好與個體差異 (如：探索型 vs 隱居型)
[ 基因 (Morph) ]      ───►  決定花紋、底色與視覺敘事 (不影響生理參數)


物種決定習性：物種決定其棲息偏好（如玉米蛇偏好垂直攀爬，豬鼻蛇偏好地底挖掘）。

個體決定差異：同物種個體擁有不同性格傾向（探索型、隱居型、攀爬型、好奇型）。

基因決定外觀：Morph 負責花色、底色與斑紋展示，絕不任意改變生理衰減率；有已知遺傳健康缺陷者則專案備註。

🏛️ 3. 核心系統架構（Data-Driven Architecture）

系統採用模組化設計，將生物資料、行為邏輯、環境運算與放歸驗證完全解耦。

3.1 物種與習性配置系統 (SpeciesConfigSystem)

負責讀取 JSON 物種設定檔，決定生物的環境需求與代謝參數：

西部豬鼻蛇 (hognose_snake)：地底挖掘者、深層底材需求、沙鏟鼻拱土行為。

玉米蛇 (corn_snake)：立體攀爬者、垂直空間與藤蔓需求、黃昏/夜間探索。

球蟒 (ball_python)：重度隱居者、高濕度需求、受驚縮成肉球、代謝極慢。

加州王蛇 (king_snake)：廣闊巡邏者、精力充沛、黑白高對比線條。

納爾遜奶蛇 (milk_snake)：樹皮縫隙匿蹤者、地表枯葉覆蓋需求、三色警示擬態。

3.2 基因與花紋系統 (MorphSystem)

管理各物種之 Morph（品系基因），提供視覺標籤、圖鑑賞析與專屬日誌描述：

豬鼻蛇：西部原色、金剛 (Conda)、極地冰雪 (Arctic Snow)、太妃糖 (Toffee-belly)。

玉米蛇：原色 (Nominal)、幽靈 (Ghost)、血紅 (Bloodred)、雪白 (Snow)、霓虹日落 (Sunglow)。

球蟒：香蕉 (Banana)、白化黃金 (Albino)、小丑 (Clown)、斑點派 (Piebald)。

加州王蛇：經典黑白高環、墨王 (Mexican Black)、香蕉王 (Banana King)、薰衣草 (Lavender)。

奶蛇：經典三色環紋、無黑純紅變異 (Hypo Milk)。

3.3 動態行為與觀察日誌 (CreatureBehaviorSystem & ObservationJournalSystem)

結合日夜四時段（清晨、白天、黃昏、夜間）、箱內設施與個體性格，自動於生態觀察日記中生成富有生活溫度的動態描述。

3.4 生理衰減與環境動態 (BiologicalDecaySystem & EnvironmentSystem)

即時監控溫濕度變化、飽足度、水分與髒汙累積連鎖反應，呈現真實生存狀態。

3.5 多層次生態放歸與安置系統 (Multi-Level Release System)

拒絕將生命作為二手商品轉售，放歸為一場需要玩家運用生態知識的觀察考驗：

三層次驗證機制：

棲地觀察：玩家觀察野外地形、溫濕度、植物、躲藏空間及攀爬結構。

生態評估：由老莫、艾咪等 NPC 協助檢驗物種適應性、原生分布、健康狀況與疾病風險（系統不提供 UI 箭頭標註，若條件不符會透過生態對話拒絕）。

生命去向記錄：

🌲 原生棲地復歸：經過完整健康與生態評估的野生個體。

🏥 保育安置：需要長期醫療或特定照顧的個體。

🔬 合作研究站：參與地下生態觀察與學術保育計畫。

🏡 永久照護：留在玩家身邊或託付給老莫、艾咪。

野外重逢彩蛋 (ReunionEventSystem)：

成功進行「原生棲地復歸」的個體，日後玩家探索對應野外區域時，有低機率遠遠瞥見其熟悉的 Morph 花紋與身影，日誌僅記載溫馨感觸，不強制重新捕捉。
