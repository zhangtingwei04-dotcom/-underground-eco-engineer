# 暖脈枝蛇｜真正 3D GLB 閉嘴基準 V0.6

日期：2026-11-14（台灣）。狀態：**已實際產出 GLB 與七視角渲染、通過工程回讀驗證；美術不合格，尚非遊戲成品。**

## V0.5 → V0.6 實際變更

- 保留 V0.5 的原創、自製、封閉連通的頭身網格與全套 3D 檢查，不重新從概念圖開始。
- 修改眼後頰、頭頂及後顱截面尺寸，讓閉嘴頭部比 V0.5 稍飽滿；**未將模型當成準確解剖完成**。
- 微調原本 24 個手工休息盤繞控制點，讓外圈、內圈的相對位置更不對稱；第二輪移除先前向上勾起的尾端。
- 改善貼地表面：身體扁圓截面與軟性底部平面形變，使身體腹側底緣更接近參考地面，但這**不是**重力、碰撞或肌肉力學模擬。
- 尾部的逐步收細起點由路徑約 **76%** 延後到 **81%**，減少長距離導線般的細尾。
- 完全不加入舌頭、張嘴、動作控制；沒有更動正式 Phaser/WebGL 24 節骨架、像素貼圖、碰撞與任何玩家存檔。

**美術仍未通過**：從側視角看，頭頸偏筆直、頭型仍過度簡化，眼眶和口角不像成熟真蛇模型；全身盤繞仍像光滑粗細接近的管狀造型，缺少真實肌肉與重力接觸形變。技術驗證綠燈不代表已達成使用者想要的生物感。

下一版應以真蛇照片和影片重新校正**頭後頰、下巴及肩頸輪廓**，並針對貼地軀幹的橢圓截面做更自然的非均勻變化。等閉嘴外形通過美術驗收，再加入獨立分叉舌頭與吐信，最後才接開合顎部及正式骨架。
