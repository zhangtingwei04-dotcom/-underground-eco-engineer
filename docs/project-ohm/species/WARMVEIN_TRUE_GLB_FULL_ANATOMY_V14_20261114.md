## 使用者要求與本輪設計

使用者希望不再一項一項詢問，直接一次改善目前 V1.3 的六大主要外形問題，完整測試後再給看。本輪以 **V1.3 原創二進位 GLB** 為唯一建模來源，**沒有下載、重用或複製 Tripo／Meshy 的模型及貼圖**；參考使用者 Tripo 截圖中可見的真蛇解剖結構，但沒有把截圖誤稱成可動畫的來源 mesh。

### 本輪集中做的幾何變化

1. **頭骨／吻端**：不是整顆頭等比縮放，而是沿 170 組 × 64 方位顱部截面，個別收斂眼後頰、鼻前和下巴，重新添加輕微顱頂／眼上弧線。
2. **眼球／眼窩／鼻孔／口線**：原創分離子網格隨顱部局部形變移動；眼球略加大、靠近側面眼窩，遠側眼加深內嵌。保留閉嘴輪廓，不加真正顎內腔。
3. **頭頸支撐**：前 146 個身體截面加入端點不動的輕微 S 形彎曲與肌肉厚度過渡；真正頭頸接面不裂開。
4. **休息盤繞**：不再僅改身體半徑，對內外圈分段使用不對稱路徑錨點，保留唯一的完整頭與尾；使用有限非相鄰截面間距取樣避免重疊。
5. **身體接地／粗細**：中後段的截面改為寬而扁的橢圓腹側、適度側向擴展及背腹壓縮，使用平滑漸變避免立刻產生硬折面。**不代表真實重力或肌肉力學**。
6. **尾部與腹側**：尾端維持細長且封閉；腹側以少量中性顏色區分背、側、腹，供幾何方向觀察。**不是正式的金色暖脈蛇皮／UV**。
