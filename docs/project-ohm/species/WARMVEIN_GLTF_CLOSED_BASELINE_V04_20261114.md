# 暖脈枝蛇｜GLB 閉嘴靜態基準模型 V0.4

日期：2026-11-14（Asia/Taipei）  
狀態：**真正 3D GLB 已建模、可讀回且工程驗證通過；美術驗收仍未通過。**

## 這次相對 V0.3 的實際改動

1. **重新設計靜止盤繞**：不用固定角速度的平面螺旋，改用 **24 個手工調整的控制點**與 C2 曲線產生不規則、鬆散的內外圈。修正頭頸接入內圈時曾出現的圓球鼓起與急轉彎。
2. **更瘦的身體與較自然尾端**：主軀幹最大半徑從 V0.3 的約 0.119（自訂單位）調到約 0.106；尾巴逐步減細。
3. **腹側貼地**：靜態身體截面略為壓扁、加寬，測試地面高度不小於 0.013 自訂單位；不代表經過重力或接觸力學模擬。
4. **頭部仍保持閉嘴**：略調吻端寬度和眼睛／鼻孔突出程度。尚未加入舌頭、張嘴、骨架或最終像素皮。
5. **模型結構仍一體**：主頭身以一個連續封閉的三角網格呈現；眼睛、鼻孔與唇線仍為分離的細節網格。

## 獨立讀回與網格驗證

- GLB 標頭為 `glTF`，可以用 `trimesh.load(...,force='scene')` 重新載入。
- 主頭身：61,922 個頂點、123,840 三角面；整個場景：130,920 三角面。
- 主模型：**一個連通封閉表面、面片朝向一致**，Euler number 2。
- 身體：1,290 個截面、每環 48 點；腹面最小高度 0.013。
- 對非相鄰段的有限 2D 中心線／截面寬度檢查，最小估計平面淨距約 **0.02369** 自訂單位。此結果**不能當作完整 3D 自碰撞通過**。
- 七個固定鏡頭均從真實 3D 幾何重新渲染，並製作四組 V0.3／V0.4 對照圖。
- **未驗證** iPhone Safari、Phaser 3 正式效能、骨架相容或真實物種的完整生物力學。

## 美術驗收：仍不合格

進步部分：盤繞不再幾乎完全等距的螺旋圈，前段接回身體不再有明顯的球狀鼓起，整體稍微修長。

仍需修正：頭後頰與眼眶過度簡化；頭頸略像一根平滑長管；盤繞與腹側仍缺少真蛇的肌肉重量感；尾部仍很細像導線；目前並非完成品。

## 下一階段

先以真蛇照片／影片進一步校正**閉嘴頭部厚度、頸部的休息支撐、尾巴與地面接觸**，再製作獨立分叉舌頭的 3D 網格（收回／半伸／全伸）。除非靜態外形目視真正過關，不能因為技術測試綠燈而直接套正式皮膚或接正式 24 節骨架。

此 V0.4 為自製低成本程序模型；沒有使用付費 Meshy／Tripo 匯出網格，也沒有更動既有玩家存檔、正式 UV、碰撞或動作控制器。
