# 暖脈枝蛇｜原創閉嘴 3D 基準模型 V0.5

日期：2026-11-14（Asia/Taipei）

狀態：**GLB 實際建模、重新載入與工程測試通過；蛇類美術驗收尚未通過。**

## 與 V0.4 相比

這輪沿用原本獨立的真正 3D GLB 靜態基準，不先接舌頭或張嘴動畫，集中檢查閉嘴外形。

1. **頭部較低、頸部更平緩**：重新配置頭部前後的 3D 中心線，降低休息時的抬頭高度，並調整鼻端到眼後的漸變截面。
2. **側面眼睛**：眼位改由頭部截面厚度、中心高度計算，眼眶與瞳孔略為嵌入表面，改善遠側眼從頭頂浮出的錯覺。仍屬簡化模型，不能稱最終眼眶。
3. **尾部比例**：縮短無支撐的末段曲線，將尾部持續變細的起點延後至身體路徑約 76%，但尾尖仍需生物外形檢查。
4. **腹側與地面**：沿頭頸及前段休息身體平順接近參考地面，避免早期試驗出現的低於地面頂點。
5. **修正原始程式錯誤**：V0.4 在身體局部寬度／高度計算時錯誤使用前一個迴圈的 `c[2]`，V0.5 改使用每個截面自己的 `cent[i,2]`。這是可確認的工程修正，不是美術完成保證。
6. **七角度驗收**：頭部近景改用**同一份 GLB 模型的前端網格裁切檢視**，移除後方尾巴入鏡的干擾；完整模型並沒有刪除尾巴。可從同方向與 V0.4 比較。
