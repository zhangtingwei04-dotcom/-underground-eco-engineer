# 暖脈枝蛇 V1.3｜真正 GLB 的靜態盤繞路徑重建

日期：2026-11-14（台灣）
狀態：**自製可回讀 GLB／OBJ 工程驗證通過，真蛇外形美術驗收不通過。**

## 背景及本輪技術決策

承接 V1.2 已可下載的原創閉嘴 GLB，以及使用者提供的 Tripo 蛇類截圖作外形研究。V1.0 至 V1.2 修眼周、頰部與接地截面的局部微調，對**整體「像規則圓管」的盤繞感**改善幅度非常有限。

V1.3 的工作範圍改為**真正重建整條休息盤繞的中心線**，先**保留 V1.2 頭部外形、眼窩、鼻孔、唇縫及尾尖**，這樣可以明確比較姿態進步，而不是一次修改所有系統。沒有複製、下載或使用任何 Tripo/Meshy 付費網格或貼圖。

## 已完成的實體 3D 幾何修正

1. 在同一份封閉頭身主網格內，對身體約 1,120 個截面的路徑施加**人工設定的多個局部 S 彎與偏移錨點**；以 PCHIP 平滑插值重排內圈與外圈的曲線，而非再等比例拉寬整條蛇。
2. **截面隨路徑切線重定位**：重建前後每環的 2D 切線角度，再旋轉各環相對中心線的截面座標，避免把變彎曲的身體當作一根被水平橫拉的管子。
3. 以不同區域的低頻腹側壓平、輕微側展與背側厚度變化模擬**靜態幾何上的貼地效果**。這是刻意區分的藝術假形變，**不是重力、肌肉模擬或有力學資料的接觸面積驗證**。
4. 身體的前約 110 環、原閉嘴頭部（170 組 × 64 點）和尾尖最後截面均保留；原本三角索引、眼睛、鼻孔、閉嘴嘴唇線及其他細節物件保持不變。
5. 真正產生 GLB 和 OBJ；從 GLB 使用實際 VTK 3D 攝影機重新繪製七個固定方向，並將 V1.2／V1.3 四個相同鏡頭並排比較。**不是重新用文字產圖當作已完成模型的渲染**。

**結論：可回退的真 3D 新盤繞基準已完成；尚未達成正式外形或動作驗收。**
