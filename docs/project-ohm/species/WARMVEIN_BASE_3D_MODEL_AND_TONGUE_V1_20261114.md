# 暖脈枝蛇｜原創 3D 基準模型與獨立舌頭系統 V1

日期：2026-11-14（台灣）｜狀態：**設計規格；不是已完成的 GLB 模型／動畫／美術驗收**。

## 0. 不再用舊口型掩蓋外形問題

玩家決定：先做真實、可旋轉、可供三方對照的**閉嘴靜態基準 3D 模型**。其後才是張嘴／吐信、骨架、像素皮與正式遊戲整合。參考使用者先前提供的蛇靜止、抬頭和張嘴影片，以及公開研究；虛構暖脈枝蛇雖有個體花紋特色，其解剖外形、行為應以真實蛇為主。

本計畫預定輸出：

- **頭部獨立基準模型**：上／下顎外形完整、短而有厚度的吻端、眼睛微嵌入，鼻孔與頭頸連續，閉嘴可從側／斜側／正／俯視查驗。
- **完整休息姿勢模型**：可檢查盤繞不規則度、身體漸細與貼地接觸，避免「螺旋管」。
- **可交換檔案**：優先真正可用的 `GLB` 與源數據，靜態外形驗收通過才考慮 rig/skin。必要時附 `OBJ` 輔助幾何檢視，但 `OBJ` 不承載正式骨架動畫。
- **對照板**：參考影格、舊 V1.1G 試驗模型與新 GLB 同角度／近似尺度比較；不要把概念渲染當作已完成 3D 下載資產。

## 1. 舌頭不是下顎的一部分

原創舌頭採獨立的 3D 子模型／節點，可在關嘴時單獨吐出，不必先把下顎張開。蛇舌透過吻端附近的唇缺（labial notch）伸出。舌頭由基部、主舌幹及左右分叉舌尖組成，兩叉應細長、漸細、略有不同相位，不能像兩根等粗的塑膠針，更不應像一塊平面紅紙。

建議節點命名（不限引擎）：
```
Snake_Head
├─ Tongue_RootSocket       // 位於口腔前部；跟整顆頭的變換走
│  └─ Tongue
│     ├─ Tongue_Stem       // 柔軟漸細、有厚度的主幹
│     ├─ Tongue_Fork_L     // 左叉，尖端收細
│     └─ Tongue_Fork_R     // 右叉，尖端收細
├─ Upper_Jaw
├─ Lower_Jaw_L
└─ Lower_Jaw_R
```
舌頭與上／下顎都是頭部的子系統，但舌頭**不可直接繼承下顎張角**。其根部跟頭部的位置姿態，伸出距離、彎曲、回縮和左右叉的微振則有獨立參數。真正模型的 Transform 不應使舌尖穿透頭頂或舌根浮出嘴外。

## 2. 兩種舌頭行為，不能和「打哈欠」綁死

### A. 關嘴吐信（chemosensory tongue-flick）

1. 關嘴狀態下主幹從唇缺伸出；嘴唇不必誇張張開。
2. 舌頭前段略彎，上下快速小幅擺動，叉端可有細微相位差；再收回。
3. 延展與回收是完整循環，收回後隱藏於口腔內，沒有長期懸掛的紅色舌頭。
4. 在接近地面、植物、陌生氣味與探索時，依行為模式選擇短暫向下探觸或空氣中的擺動；不把吐信一律等同於某種情緒。
5. 活動率與連續次數依物種、環境、興奮度與真影片校正，不硬塞固定每 N 秒吐信。

### B. 大張嘴／疑似「打哈欠」

- 大張嘴是**顎部、口角、喉部與頭頸**各自的動作；舌頭可能保持在口腔內，不需每次跟著往外甩。
- 若玩家提供的真蛇影片明確看到舌頭在張口時位移，再新增該情境下的舌頭微位移與可見度；不能自行發明「張嘴必吐信」的刻板動畫。
- 不把「張嘴」直接判斷為疲勞；不同情境還應與進食、緊迫、呼吸異常的生理因素區分，不能全部叫哈欠。

## 3. 原創 3D 幾何與像素風兼容

- 中性灰／暖灰幾何作對照基準，舌頭調成低飽和、略偏玫紅或深紫紅，顏色仍以真實參考及暖脈枝蛇虛構設定審美調整。
- 舌幹用低面數但有厚度、可沿 3D 曲線變形的網格；二叉使用獨立曲線控制，不固定成完全平整的 V。
- 近景使用真正 3D 舌叉網格；遠景若舌尖在像素化後不足 1 像素，允許加強可見度或降低繪製複雜度，**不允許不合理地把整條舌頭放大**。
- 建議由 `tongueLengthRatio`、`forkSeparation`、`flickAmplitude`、`oscillationPhase` 控制；所有初值**是可調視覺參數，不是已量測的物種生物數據**。
- 對幼蛇／成蛇以頭部局部尺度決定模型大小，不拿世界座標固定長度硬套到不同成長階段。

## 4. 分階段驗收與影格證據

1. **V0 靜態閉嘴**：頭部／全身 GLB 輸出，四角度檢查頭型、眼窩、口角、頸部、身體盤繞，先排除管子、尖錐頭與穿模。
2. **V0-T 舌頭靜態形體**：真正從唇缺伸出主舌幹與兩叉，完成 0%、50%、100% 伸出三個固定姿勢，正／側／斜側都要看得出雙叉且不穿模。
3. **V0-TF 吐信循環**：伸出→有限擺動→回縮。與真實影片／研究的行為方向比對，不能只確認 WebGL2 執行成功。
4. **V0-Yawn 顎部**：閉嘴、微張、中張、大張的獨立靜態口型優先驗收；再加頭部輕仰、頸部支撐和口腔形變。舌頭不強制吐出。
5. **整合前閘門**：舌頭原生模型與頭部骨架 attachment、側視只露近側眼、各角度沒有遠側舌叉錯位與顎部穿模、四階段成長相容。合格後才接入舊 24 節骨架、現有 Phaser/WebGL、UV/像素皮與存檔。

## 5. 科學參考與適用限制

- 英國自然史博物館：蛇以分叉舌拾取環境化學資訊並傳到口腔上方的鋤鼻器。https://www.nhm.ac.uk/discover/snakes-senses-stretchy-jaws-deadly-venom.html
- Merck Veterinary Manual：蛇可在嘴閉合時經吻端唇缺吐信；不是每次都要把下顎大幅張開。https://www.merckvetmanual.com/exotic-and-laboratory-animals/reptiles/clinical-procedures-for-reptiles
- Daghfous et al. 2012，`Chem Senses`：研究 `Nerodia fasciata` 吐信運動，區分空氣中振盪與朝物體／底材向下伸出的行為。這是**他種蛇的研究**，不能直接把所有頻率照抄至玉米蛇的對應虛構物種。https://pubmed.ncbi.nlm.nih.gov/22942105/
- 2022 年 `Integrative and Comparative Biology`：水蛇在不同環境使用不同吐信模式，證明情境依賴，不能視為一種固定擺動。https://academic.oup.com/icb/article/62/4/852/6601462

**驗收原則**：有檔案、能旋轉、有測試綠燈 ≠ 外觀已像真蛇。只在已人工檢查真 3D 多視角且與來源片段比對後，才報告對應階段通過。
