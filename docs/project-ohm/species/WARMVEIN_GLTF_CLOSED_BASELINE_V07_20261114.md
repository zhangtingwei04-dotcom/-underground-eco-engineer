# 暖脈枝蛇｜原創閉嘴 3D GLB 基準 V0.7

日期：2026-11-14（台灣）。狀態：**GLB/OBJ 實際建模、獨立讀回與七角度渲染成功；美術驗收尚未通過。**

## 這一輪的重點

延續 V0.6 真正閉嘴 3D 模型，不回頭修改之前的 V1.1G 張口動作。只針對**眼後頰、下顎外部厚度、自然休息盤繞及身體接地截面**修改。具體已實作：

- 頭部的眼前、眼後臉頰寬度與下半部輪廓使用新控制點。第二輪降低過度鼓起的下頰，保留原本短吻及嘴縫。
- 略調眼眶與眼球在表面中的嵌入深度，讓側視能看清眼睛但不要讓遠側眼睛明顯浮出頭頂。
- 重新微調 24 個不對稱的休息盤繞控制點，讓不同圈的彎曲與位置不過度規則。
- 身體中後段半徑與腹部扁平度採較不均勻、緩慢連續變化；保留接地軟壓形變但**不宣稱重力或肌肉模擬**。
- 尾部依舊由後約 82% 的路徑開始逐步細化，保留完整封閉單一頭身主網格。
- 沒有加入舌頭、張嘴、正式骨架／24 節控制、UV 像素皮、碰撞或遊戲存檔整合。

獨立驗證（trimesh 重新讀取原 GLB）：
- 主頭身網格：**61,922 頂點、123,840 三角面**；全場景總計 **130,920 三角面**。
- 主網格封閉、一個連通分量、面片朝向一致（Euler number 2），每環 48 點，共 1,290 環。
- 主網格最低 z 約 **0.01354**，相對地面參考面 z=0。
- 身體低於 z=0.020 自訂單位的頂點，V0.6 約 **18.83%**，V0.7 約 **18.78%**：**沒有顯著改善整體接觸範圍**；低於 z=0.016 的頂點約從 8.9% 增加到 10.21%，屬局部壓扁外形差異，不能解讀為真的重量模擬。
- 有限抽樣的非相鄰路徑 2D 預估淨距約 **0.02507**，比 V0.6 的 0.03828 **縮小**。它不等於全面三角面 3D 自相交驗證，所以後續不能不受限制地擴大身體寬度。

## 實際多角度自審

- 頭後頰比前版厚實，閉嘴外輪廓有部分改良。
- 眼睛稍微清楚，卻仍像貼在頭部的小橢圓，眼眶與口角未符合真蛇外觀。
- 吻端仍偏楔形、前端切線不夠圓順，頸部仍有均勻管狀感。
- 盤繞和腹面仍像程序化圓管，**重量感是未解決項目**；不能僅靠測試通過宣稱完成。
- 目前未在 iPhone Safari 或正式 Phaser 3/自研引擎評估效能與相容性。

**結論：工程驗收通過；美術仍未通過。** 下一輪應更重視真蛇的頭骨／眼眶／嘴角的多視角雕塑，以及非均勻橢圓截面的身體接觸。通過閉嘴基準外形後才建立獨立分叉舌頭；最後才是張嘴與骨架動畫。
