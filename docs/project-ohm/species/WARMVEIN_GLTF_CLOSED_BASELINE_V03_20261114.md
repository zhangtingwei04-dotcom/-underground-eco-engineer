# 暖脈枝蛇｜獨立真實 3D 閉嘴靜態基準 V0.3

日期：2026-11-14（台灣）。**工程驗證通過，藝術驗收不通過。**

## 與 V0.2 的核心差異

本版不再修正舊 V1.1G 的張嘴動畫，而是直接以**真正可匯入 3D 軟體的原創 GLB 基準網格**測試閉嘴靜態輪廓。

- 重新調整眼前吻端的輪廓與厚度，保留眼睛／鼻孔／閉嘴唇線作為獨立小部件。
- 整顆頭、頸部和全身盤繞由**一個封閉連通主網格**表示，採連續 3D 樣條中心線、48 方位環向截面及平滑的頭頸截面曲率，改善 V0.2 頭頸處的視覺切線。
- 休息盤繞中心線引入更多不對稱變形並保留自然收細尾端；頭的高度較 V0.2 略低。這仍是初期程序化造型，不是已驗收的自然盤繞。
- 重新匯出 GLB 與 OBJ，並由**實際 3D 網格**在固定側／斜側／正／俯視角度渲染 7 張檢查圖；另製作四組 V0.2 與 V0.3 同角度比較。
- **沒有**修改公開站上的正式蛇類動作、原始 24 節骨架、現有 UV、碰撞、存檔、私有遊戲檔案或任何玩家資料。

## 三輪靜態外形自審

1. 第一輪：頭頸接面比 V0.2 少了明顯線痕，但吻端出現圓球狀鼓起，無法通過美術驗收。
2. 第二輪：改善鼻端頭寬分布、略降低頭部仰角並平滑頭頸截面；吻端反而一度偏尖，再次退回。
3. 第三輪：調整眼前吻端長度與橫向截面，並提高休息盤繞曲線的不對稱程度，最後通過 GLB 結構檢查，但**仍有顯著的塑膠管和規則螺旋感，不能稱為真蛇成品**。

### 尚未解決

- 盤繞不是自然蛇類的肌肉支撐、堆疊接觸與重力模擬；雖已不對稱，仍偏幾何螺旋。
- 頭的後頰與吻端、眼眶、鼻孔需要更精細的真蛇多角度外形參考。不要靠貼圖掩蓋錯誤幾何。
- 真正的顎部內腔、舌頭、可開合骨架及動畫尚未做進 V0.3。
- 沒有驗證 iPhone Safari、真正的 Phaser 3 或自研引擎上是否順暢，不能聲稱跨平台已可用。
