## 這次已直接提交的幾何修正

### 第一輪：從 2D 硬板到 3D 顎部

- `warmvein-static-anatomy-v11e.mjs`：每側下顎改為連續的 **22 邊圓弧管狀截面**（不是先前單片薄平面），四口型仍由同一份幾何規則產生。
- 在吻端增設下顎前端連接曲面（`anterior_chin_bridge`），將暗紅色口腔底面改為**內縮的 U 形盆面**（`recessed_oral_basin`）。
- 第一輪 Chrome 圖證明舊 V1.1D 那片大紅色三角面明顯縮減，但張大嘴仍像兩根獨立細骨條。**美術不通過。**

### 第二輪：補充下巴的柔軟包覆

- 增加 `curved_ventral_chin_skin` 曲面，讓左右下顎底部有完整弧形皮膚輪廓。
- 舊 24 節動作骨架、碰撞、雲端及玩家存檔不改。
- 第二輪 Chrome 圖可見下顎開始有面積與厚度，但口角接到頸部仍突兀。**美術不通過。**

### 第三輪：改善下顎與喉部交接

- 再增加 `cheek_throat_flex_transition`，在口角後方逐漸連接固定喉部與下顎。
- 對兩側下顎截面加厚、調整腹側下巴曲率，保留完整吻部形狀、鼻孔及眼睛位置。
- 單元測試檢查新三維下巴、喉部過渡面、嘴型張幅的單調變化及來源隔離。

## 尚未達標、不應繼續誇稱完成的部分

1. **靜態完整蛇形**：頭頸到身體仍需重新建立可信曲面，休息盤繞的重量感不足。
2. **顎部自然度**：大張嘴時下顎的外輪廓仍偏長、細；上下顎的口腔接合面與彈性軟組織目前只有顯示層簡化，尚無真實生物力學驗證。
3. **細節**：眼眶、鼻孔、口角、牙齒與口腔上方細節尚未精雕；當前只是灰褐色中性材質，未套正式暖脈枝蛇 UV 皮膚。
4. **完成門檻**：仍需先通過完整 3D 靜態四視角美術驗收，之後才能接回正式 V0.9U／24 節骨架，然後才做真正張嘴、閉嘴的連續動畫。

## 隔離原則

V1.1E 僅位於公開 `qa/snake-skin-v10b/static-head/` 的實驗室。正式 24 節動態、玩家存檔、NPC、私有遊戲內容均未更新。所有展示均是自建程序化模型，不使用或複製 Meshy/Tripo 的下載付費資產。公開版本已經開發者同意。

**工程結論：可繼續作為靜態張嘴結構的改良基底；美術結論：不應稱為真正像蛇的完成版。**
