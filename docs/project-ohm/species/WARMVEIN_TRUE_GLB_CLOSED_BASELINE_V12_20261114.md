## 本輪背景與參考限制

使用者提供六張 Tripo Studio 橙棕蛇模型行動版截圖，作為眼眶、後頰、腹鱗轉折與休息姿勢的可見外形參考。相關原始觀察已記載於 [Tripo 截圖研究](WARMVEIN_TRIPO_VISUAL_REFERENCE_REVIEW_20261114.md)。**沒有下載、解包、重用或上傳 Tripo 模型、UV 貼圖、使用者原始截圖**，本輪只使用自製數學曲面修改先前 V1.1 的原創 GLB。

本輪仍堅持「先閉嘴、靜止外形像蛇，才做舌頭與張嘴」的使用者既定原則。

## 實際編修範圍

1. **眼周**：對 V1.1 的頭部 64 環向取樣雕刻局部眼窩凹面、眼上脊、眼後頰與下唇外側，而非整個頭部一起縮放。重新在修改後的表面安置眼眶、眼球及鼻孔，優先減少斜側視圖的遠側眼凸出。
2. **口角**：同一閉嘴頭部表面加上沿上／下唇邊界延伸的細窄唇縫線，**尚未建立內腔、可開合顎部或任何張嘴動作**。
3. **腹面**：針對中段的 48 點身體截面，使用漸進式軟扁平化的局部形變；接地後方沿線寬度較自然，但沒有實際肌肉模擬、重力或碰撞。
4. **顯示材質**：使用較暖的中性灰米色，腹側略不同於背側以顯示截面轉折，頭頸顏色緩慢過渡。**不是正式暖脈枝蛇金色脈紋／鱗片貼圖**。
5. **來源隔離**：保留吻端最前 8 環、顱部最後 30 環及身體第一環、尾端最後 20 環的原有座標，網格連通結構和所有三角面索引數量不變；V1.1 GLB 作為可回退來源。

## 多角度外形自審：依舊未通過

比 V1.1 更可見的地方是眼窩周圍的局部陰影、眼球縮進側面及腹側連續材質；但這些仍是**局部修正**，整顆頭的正面輪廓依然圓鈍，細節缺少真蛇上下顎／嘴角的解剖差異。完整盤繞在遠景仍是過於規則的平面圓管，貼地重量感沒有根本改善。不能因為較 V1.1 增加 1.51 個百分點的近地面頂點就誇稱已像真蛇。

### 下一個正確技術決策

停止僅靠局部眼窩及截面小幅變形累積版本號；應依**真蛇的靜止側面／俯視／正面影格**先重新設計完整休息中心線、身體局部堆疊、背腹截面方向及顱部自然外輪廓，再用實際多角度對照確認有大幅度視覺改善。**這是靜態基準模型，尚未加入舌頭、張嘴、真正動畫骨架與正式像素皮。**
