# 跨裝置同步：安全決策階段（2026-11-08）

新增純函式 `src/systems/save-sync-policy.js`，用於判斷同步方向，不包含任何自動資料寫入。正式遊戲未啟用本功能。

## 規則
- 無雲端回應：暫停同步，不假設雲端是空的。
- 裝置沒有本地進度且雲端有存檔：可以下載雲端資料。
- 裝置有舊本地進度但沒有可信任的 `localBaseRevision`：要求人工選擇，不可自動覆蓋。
- 本地修改（dirty）與雲端版本分歧：顯示衝突，不自動上傳或下載覆蓋。
- 本地資料有改動，且基礎版本與雲端版本一致：允許帶 `expectedRevision` 上傳；最後由伺服器 409 保護。
- 本地資料未改動、雲端版本更新：允許下載。
- 所有寫入都應保留對應歷史版本；離線寫入先保存本地副本，待線上確認版本後才同步。

## 跨裝置唯讀驗證
在 `cloud-save-test.html` 新增「跨裝置唯讀比對」按鈕；兩台裝置登入同一專用測試帳號後，應顯示相同版號、測試標記，且不進行寫入。請勿分享 access token 或密碼截圖。

## 剩餘事項
- 模組化的本機 durable backup、衝突選擇 UI、實際雙裝置測試、發送到雲端的節流策略。
- Auth 與正式 SaveSystem 整合、登出清理、獨立定期備份、版本保留策略。
- 目前正式遊戲仍用舊存檔流程，未啟用 Cloudflare 自動同步。
