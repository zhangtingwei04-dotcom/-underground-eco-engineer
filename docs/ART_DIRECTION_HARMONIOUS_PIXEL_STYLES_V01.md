# 《鱗片與種子：地下生態物語》像素美術方向 V1｜融洽的多層次像素世界

日期：2026-11-08
狀態：**使用者確認的美術方向與未來生成分工；正式素材逐張製作、檢查與替換。** 此文件只定義風格，不代表圖片已生成或上傳。

## 1. 美術核心與創作原則

**溫暖 × 自然 × 融洽。**

《鱗片與種子》是溫柔的地下生態研究站生活遊戲。美術以**像素作為共同視覺語言**，但不要求所有背景、角色、動物與 UI 都使用完全相同的像素密度、輪廓筆法或細節層次。

**可以有不同的像素表現形式，只要像出自同一個歐姆世界。** 優先維持共同的色彩關係、光源邏輯、材質特徵、構圖尺度、輪廓清晰度與情緒氣質，而不是僵硬地把所有物件複製成同一種模板。

玩家最直接的感受應是：自然、親切、有生命力、稍帶奇幻、可長時間觀看但不刺眼；生態與研究有可信感，卻不是冰冷或硬核的實驗室。可借鑒《Kamaeru: A Frog Refuge》的溫柔棲地觀察與舒適感，但**不複製**它的具體畫作、角色、介面、佈景或作品識別。

## 2. 五類素材容許不同像素表現

| 素材類別 | 適合表現 | 必須連貫的元素 | 特別避免 |
|---|---|---|---|
| 主場景／地下城／研究站 | **精緻環境像素**，柔和局部光、豐富植物與地質材質；細節以空間深度分配 | 木、石、泥土、苔蘚、菌菇、水、微光的可信色彩；互動區域清楚 | 整張霧化成油畫、過度擬真照片拼貼、冷硬科技主導 |
| NPC／生活物件 | **清楚角色像素**，個人輪廓、衣著、表情與身份特徵易辨；可以比背景更鮮明 | 身形比例、視角、落影、角色專屬配色與世界文化一致 | 全體角色一個模子；高細節背景使角色辨識困難 |
| 爬蟲與生態飼養箱 | **細緻可觀察像素**，物種的頭型、斑紋、體態、移動與藏身位置可區分 | 真實蛇類解剖結構與可觀察行為；和底材／植物／枝條接觸合理 | 卡通手腳、擬人表情、為了可愛犧牲物種辨識；不符合物種的生態箱 |
| 木質 UI／按鈕／視窗 | **乾淨且可讀的精緻像素**，木紋、雕框、少量暖金屬配件；像研究站器具而非塑膠面板 | 尺寸、互動狀態、文字對比、一致的邊框及圖示語言 | 按鈕過大擋場景、木框太厚、文字難辨、冷色全息 UI |
| 圖鑑／圖書館／雜誌 | **插畫感像素**，帶一點手工書籍與自然筆記氣質；重視內容留白 | 圖／名稱／2–3句簡單生態／1句可愛小簡介；詳細研究可選展開 | 長篇硬塞主頁、假論文圖表、每頁都堆滿動物裝飾 |

**不同表現形式不代表毫無比例約束。** 同一畫面中的物件需共同遵守透視、光向、地面接觸、色階及像素放大方式；組合後若出現明顯畫風斷層，應重新調和。不要把 8-bit、手繪插畫、3D 照片任意貼在同一畫面稱為混合像素風。

## 3. 共通色彩、材質與光影語言

- **基底：** 暖木褐、泥土赭、岩石灰褐、深苔綠、柔和植葉綠。
- **點綴：** 菌菇和地下植物的微光青綠／青藍、琥珀色提燈、少量晶礦色；裝飾色不搶過動物或重要文字。
- **明暗：** 暖色人工照明與自然反射光；光源方向具一致性。暗處仍可辨識可互動物件，不以整畫面過黑營造氣氛。
- **材質：** 木頭有自然紋理與磨損；石與礦物有層次但避免過度反光；苔蘚、落葉、水面保有柔和結構，不要製成像黏土的單一材質。
- **色彩彈性：** 歐姆各區域可以有不同季節、地熱、礦石與植被色系；不同區域可各有辨識度，但仍共享溫暖、自然、低壓迫感的基調。
- **可讀性：** 角色、動物、主要按鈕與場景互動點優先清晰；暗場可用適量輪廓光、底色對比和層級，而非一味增加亮度或粒子數。

本版本不硬性限制固定色票數、像素格大小或所有圖共用單一解析度。未來可依實際一組素材做比對後建立色票與倍率規範，而不是先拍腦袋鎖死數值。

## 4. 互動與裝置規格

- **第一人稱 2D 場景**：玩家透過圖片場景與底部可前往地點名稱移動；景物以空間尺度與畫面焦點說明互動位置，不增加不必要的動態 UI 遮蔽。
- **直式與橫式**：使用各自適當構圖／安全區，不強行拉伸同一張背景；保留標題、按鈕、訊息視窗及動物可視範圍，手機上亦須檢查。
- **像素清晰度**：重要精細像素若被混合縮放造成模糊，需透過對應縮放、適合輸出尺寸或分層重製解決；不能僅因有「像素質感」就忽略鋸齒、模糊或陰影融合問題。
- **遊戲效能**：動物動畫優先分層或小張序列；大型場景需要時壓縮、裁剪、延遲載入與重用資源；不能為追求無限粒子、超大貼圖犧牲手機流暢度。
- **素材分工**：場景、可互動物件、動物、NPC、前景特效、UI 適合分層製作；透明背景資產需確認正確 Alpha，**不能把黑色預覽底圖誤當透明貼圖**。
- **多語系**：普通 UI 文字優先維持可替換的多語言內容，避免將大量翻譯烘焙進背景；主畫面完整 Logo 例外，依已核定的十語言**各自獨立圖片**制度製作。

## 7. 檢查一張圖是否「屬於《鱗片與種子》」

用五個觀察問題判斷（不做數值考試）：

1. 它看起來是同一個**溫暖、自然、略帶奇幻的歐姆世界**嗎？
2. 與其他已確定場景／NPC／UI 放在一起，**光影、輪廓、色調與尺度**和諧嗎？
3. 動物是否能辨識真實物種，沒有不必要擬人化或明顯不符合棲地的造景？
4. 手機直橫式是否可辨識，主標題、按鈕、對話、動物重點有呼吸空間？
5. 能否用合理大小、性能與資產格式**真正放進 Phaser 遊戲**，而非只能當靜態參考圖？

若某項衝突，先改圖像，**不因圖好看就擅自修改已核准的核心玩法或 NPC 設定**。

## 11. 2026-11-09｜畫風正式主軸：精緻繪本式像素 × 局部手繪光影

**使用者確認：** 正式選用 **A「精緻繪本式像素風」為整體主畫風**，並在**地熱纜車、大型地下建築與特殊空間**採用少量 **C「2D 手繪式奇幻光影」** 作為輔助。這是 V1「溫暖 × 自然 × 融洽、容許不同像素細節密度」的具體化，**不是**放棄像素視覺而轉成完整手繪動畫風。

### 主畫風規範
- **視覺重心：** 自然、舒服、細緻而可讀的繪本式像素背景；人物與重要操作物件保留乾淨的像素輪廓，畫面像來自同一座有人生活的地下生態國家。
- **光影輔助：** 暖色窗光、提燈反射、地熱餘光、礦石與菌菇的柔和環境光可以帶些手繪暈染質感；但保持主要像素輪廓與透視一致，避免主場景變成模糊插畫。
- **比例屬氣氛建議，不是工程硬數字：** 以「約七成自然奇幻感、三成復古機械感」為美術方向參考；森林、住處、博物館與地下城市以生態／生活為核心，地熱纜車、橋梁、車站等科技構造可以增加一些復古金屬機械細節。
- **色彩與材質：** 苔蘚綠、自然木棕、柔和琥珀、洞穴紫及少量晶礦青。木質、石材、植被和金屬保有自然紋理；光源明確、降低過度螢光效果。
- **地熱纜車：** 保留圓潤復古車廂、大片玻璃窗、木質內裝、銅色零件、暖色燈光與車頂懸吊輪組。簡化不必要的裝飾，確保多節串聯、空中吊掛與候選的下降接軌機構容易辨識；先前生成概念圖為風格參考，不代表其文字、尺寸或機械工程已定案。
- **地下城市與大型景觀：** 可以用柔和手繪式遠景光影增強巨大洞穴、橋樑、瀑布與城鎮層次，但不要讓每個場景都變成過度華麗的觀光海報。
- **NPC／動物／生態箱：** NPC 保持表情及輪廓辨識；現實物種以解剖、比例、真實行為及照護環境正確為優先，不能為符合繪本風格而失真。木質 UI、圖鑑與多語主標題沿用已確認的個別規格。
- **實際遊戲資產：** 仍依第一人稱 2D 場景、手機直橫式畫面、安全區與效能條件逐張產出／驗證；畫風混合不應造成縮放模糊、圖層不可分或動畫無法實作。

### 現有成果保護與適用範圍
- 不覆蓋已確認的主畫面、標題、十語系素材、保留於檔案庫的生物像素示範母版或玩家存檔。

## 12. 2026-11-09｜研究野帳與生態研究圖鑑的視覺區隔（已確認）
