# 首個可互動生態觀察小功能（2026-11-08）

## 已更新
- `src/systems/terrarium-observation-interaction.js`：從既有遊戲狀態讀出當前生態箱、真實記錄的動物數量、溫度、濕度與潔淨度；不存在時不杜撰數值。
- `src/scenes/UndergroundScene.js`：新增「🔎 觀察生態箱」操作，寫入現有 `ObservationJournalSystem` 的 `environment` 類型日誌，並透過現有 `gameSaveManager.saveGame()` 儲存。
- 不增加額外登錄、付費服務、每日強迫任務或 AP 消耗；不推測動物疾病、行為、心理與物種適應性。
- 保留原有場景、設定、圖鑑、生態箱及雲端測試功能，不更換正式遊戲存檔提供者。

## 驗收待辦
1. 在遊戲內進入 UndergroundScene，確認「觀察生態箱」按鈕可見與可點擊（手機直橫式需檢查）。
2. 有生態箱時顯示實際數值，缺少環境數值時不填入假數據。
3. 確認觀察日誌新增且存檔成功；重新進入場景後仍保存。
4. 無存檔、無生態箱或儲存失敗時，必須顯示安全提示，不造成遊戲崩潰。
5. 進一步改善觀察日誌 UI 與科學性：加入物種對應的適宜環境參考範圍前，不能直接判定「健康 / 生病」。
6. 此為小步功能更新，未宣稱完成手動瀏覽器功能測試。

## 後續目標
- 按使用者已確認的第一人稱 2D 場景方式，逐步把研究所區域與生態箱觀察做成可探索互動流程。
- 依動物習性增加科學可驗證的觀察事件，而非隨機擬人化敘述。
- 保留模組化，將邏輯與美術逐步拆分。
